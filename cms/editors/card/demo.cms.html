Editor Card: the entry as a CMS sees it

The card content model is one model: everything shared is a native CMS field — the envelope — and everything type-specific lives in a single JSON field called details, edited by <editor-card>. This page plays the CMS host: the envelope groups below are ordinary form fields (in a real CMS, Contentful or Umbraco renders these natively), and the Type Details group is the one JSON field.
