Custom Easings

Apply custom easings with the easing attribute. 81 values ship — 12 families in 5 steps each plus 21 named curves (ui/base/easings.css, wired in ui/base/animate.css):

ease-1…5 · ease-in-1…5 · ease-out-1…5 · ease-in-out-1…5 · ease-spring-1…5 · ease-bounce-1…5 · ease-elastic-1…5 · ease-elastic-in-1…5 · ease-elastic-out-1…5 · ease-elastic-in-out-1…5 · ease-squish-1…5 · ease-step-1…5
Named curves in -in / -out / -in-out triples: ease-quad-* · ease-cubic-* · ease-quart-* · ease-quint-* · ease-sine-* · ease-expo-* · ease-circ-*

slide-in() with easing="ease-elastic-1"

Pace — Entry Speed

Control how quickly the animation completes during entry. Default is entry 0% to entry 75%.

fade-up() fast

Narrow scroll range — snappy animation.

<lay-out animate-self="fade-up() fast" lg="columns(3)">

fade-up() slow

Full entry phase — gentle animation.

<lay-out animate-self="fade-up() slow" lg="columns(3)">

fade-up() very-slow

Widest range — very gradual animation.

<lay-out animate-self="fade-up() very-slow" lg="columns(3)">

zoom-in() very-fast

Narrowest range — instant feel.

<lay-out animate-self="zoom-in() very-fast" lg="columns(3)">

Pace — Exit

Add an exit token to play the animation in reverse as the element scrolls out.

fade-up() exit

Fades up on entry, reverses on exit.

<lay-out animate-self="fade-up() exit" lg="columns(3)">

zoom-in() exit-fast

Zooms in on entry, snappy reverse on exit.

<lay-out animate-self="zoom-in() exit-fast" lg="columns(3)">

flip-up() exit-slow

Flips up on entry, slow reverse starting in contain phase.

<lay-out animate-self="flip-up() exit-slow" lg="columns(3)">

Pace — Combined Entry + Exit

Mix entry speed and exit tokens for independent control.

<lay-out animate-self="fade-up() slow exit-fast" lg="columns(3)">

zoom-in() fast exit-slow

Fast entry, gradual exit.

<lay-out animate-self="zoom-in() fast exit-slow" lg="columns(3)">

reveal(inset) very-slow exit

Very slow entry, reverse on exit.

<lay-out animate-self="reveal(inset) very-slow exit" lg="columns(3)">
