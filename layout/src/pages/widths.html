Width Tokens

The width attribute constrains the layout to predefined max-widths.
Available tokens: xs, sm, md, lg, xl, xxl.

Width Tokens

Each token maps to a CSS custom property for consistent sizing.

lg, xl and xxl are wider than the page's own content column (--layout-bleed-mw, 1024px by default), so on this page they would all clamp to the same width and look identical. They are shown with bleed instead: the band escapes the column and spans the viewport, while width keeps constraining the content inside it. They also carry a theme and p(2) padding so each band is visible.
