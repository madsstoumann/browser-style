Stack Layouts

The stack() layout overlaps all children in the same grid cell (--layout-ga: 1 / 1). Use any custom name — stack(hero), stack(overlay), stack(my-thing) — the selector matches on stack(, so the CSS is always the same. Layer order follows DOM order: last child on top.

One name is special: stack(reveal) additionally turns the layout into a sticky full-height cage and redirects an animate-self="reveal(…)" onto its last child — see reveal-stack.html.
