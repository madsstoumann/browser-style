Carousel Controls

A <lay-out overflow> is a snapping scroller. Controls come from the media= token attribute — the same vocabulary <ui-media> uses, styled by ui/carousel/carousel.css. Dots are ::scroll-marker and arrows ::scroll-button(), so they are native in Chromium only; elsewhere /ui/carousel/polyfill/carousel.js injects real buttons styled from the same tokens. loop and auto() are JavaScript progressive enhancement — everything else on this page is CSS-only.

The geometry tokens (preview*, center, frame, gaps, stop) live on the overflow attribute — see overflow.html.

Note: axis(y) and mrk(rail) are <ui-media>-only — a <lay-out overflow> scroller is always inline-axis.

Paging — pages

Every other section on this page is columns(1), so one marker means one slide. Multi-column needs pages: it snaps and draws one dot per page of --_ci items instead of per item, so the dot count follows the columns() token and adapts per breakpoint. Without it the markers stay per-item and jump --_ci places per step. Resize to see the count change.

pages

2 columns at md, 3 at lg — 3 dots then 2

<lay-out md="columns(2)" lg="columns(3)" overflow media="nav pages mrk(blw)">

pages — 4-up

4 columns at lg — 2 dots

<lay-out md="columns(2)" lg="columns(4)" overflow media="nav pages">

Autoplay and loop — JS

auto() and loop are progressive enhancement, driven by the shared carousel engine in @browser.style/card (ui/card/carousel.js). Everything above is CSS-only.
