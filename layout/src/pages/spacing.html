Spacing Demos

Spacing is token-only — card-style tokens embedded in the breakpoint attributes (there are no bare pad-*/col-gap attributes). Tokens use a multiplier applied to --layout-space-unit. The lowest breakpoint (xs, un-media-queried) is the mobile-first base that applies at all widths; larger breakpoints override it. Resize the viewport to see the overrides.

Note: this build generates spacing tokens for the xs and lg breakpoints only (the spacing.breakpoints allowlist in layout.config.json). Add more breakpoints there to author spacing at those tiers too.

All-sides padding — p()

Base padding p(1) on all sides (from 0px up), growing to p(4) at lg. <lay-out xs="columns(2) p(1)" lg="columns(4) p(4)">

Padding-inline & padding-block — pi() / pb()

Inline padding grows from pi(1) (base) to pi(4) at lg; block padding pb() sets top + bottom together. <lay-out xs="columns(2) pi(1) pb(1)" lg="columns(4) pi(4) pb(2)">

Asymmetric block padding — pbs() / pbe()

Block-start (pbs) and block-end (pbe) set independently — here more padding at the bottom. <lay-out xs="columns(2) pbs(1) pbe(2)" lg="columns(3) pbs(2) pbe(4)">

Margin spacing (block only) — mbs() / mbe()

Vertical separation between layouts using mbe (margin-block-end). The gap below the first grid grows at lg. (Margin is block-only — margin-inline stays auto for centering.) <lay-out xs="columns(2) pb(1) mbe(2)" lg="columns(2) pb(2) mbe(4)">

Gap control — cg() / rg()

Column gap and row gap controlled independently. Small gaps at the base, wider at lg. <lay-out xs="columns(2) cg(1) rg(1)" lg="columns(3) cg(2) rg(3)">
Zero gaps — removing all spacing between items. <lay-out xs="columns(3) cg(0) rg(0)" lg="columns(4) cg(0) rg(0)">

Combined tokens

Multiple spacing tokens in a single attribute — padding, gaps and margin, all set at the base and overridden at lg. <lay-out xs="columns(2) pi(1) pb(1) cg(1) rg(1)" lg="columns(3) pi(3) pb(2) cg(2) rg(2)">

Base (xs) + breakpoint override

The xs tokens are the mobile-first base — they apply at all widths because xs has no media query. At lg, the pi(3) token overrides pi(1). <lay-out xs="columns(2) pi(1) pb(1)" lg="columns(3) pi(3) pb(2)">

Grid layout with spacing

A grid layout pattern with responsive spacing — compact at the base, spacious at lg. <lay-out xs="grid(3a) pi(1) pb(1) cg(1)" lg="grid(3a) pi(3) pb(2) cg(2) rg(2)">
