Browser.style

UI: Search

<ui-search> wraps a native <search> landmark and a GET form. With no script, or no api=, the form submits to its action= like any form. With api=, the same form fields go to a JSON endpoint and come back as a list of links. This page has no backend: the three demos read data/demo.json and filter it in the browser.

Quick results

The header above: trigger="input" searches as you type (after three characters and a 300 ms pause), variant="bar popover" joins field and button and floats the results under them while the search has focus. Enter still submits the form to the results page. Arrow keys move between the field and the links; Escape closes the results.

Results page

trigger="submit" runs on Enter instead of on every pause — right for a semantic backend, where each new query is an embedding call. sync-url writes the query into the address, so the page can be shared and reloaded. results="…" draws the results outside the <search>, in the page's own content, where a results page keeps them. The filter is just another form control.

Your own markup, and other languages

A <template data-search="item"> replaces the default row; data-field names what goes where, always as text. The status line takes its words from label-* attributes, one per plural category of the page's language.

When the endpoint fails

The status line says so, and Enter still submits the form natively unless trigger holds submit.

Agents

The header's form is also a WebMCP tool, search_site: toolname, tooldescription and toolautosubmit on the form, toolparamdescription on the field. When a browser's agent submits it, the element answers with the whole response instead of leaving the page, extra fields included (the silk gown's product), and draws the results for the person to see. Browsers without WebMCP ignore the attributes. One tool per page. See readme.md § Agents.

Structured data

The component writes no microdata. The site's one WebSite item — the hidden block at the top of this page — carries the SearchAction, and its urlTemplate is this page's form: action plus the field named q. Three search boxes, one WebSite. See readme.md § Structured data.
