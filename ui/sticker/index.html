UI: Sticker

CSS

<ui-sticker> is a CSS-first promotional callout — a round disc by default, or a 24-point starburst with variant="burst". Use color for any single color (auto-contrast ink), theme for preset bundles, and size for scale.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version.

Shapes

Use variants burst, spark, sunburst, heart and blob.

Each line is a semantic element — <small> for a label, <strong> for the headline — with preset cqi sizes, so no inline font-size is needed and the text scales with the box.

Theme

Use theme for a decorative color bundle (background + ink), distinct from the semantic color axis. If both are set, theme wins.

Multi-line

Each direct child is its own line; use variant="gap(sm|md|lg)" for line-spacing. <small> (label) and <strong> (headline) give preset, fluid cqi sizes — no inline styles.

Speech balloon

Use variant="speech(l)" or speech(r)" for a rounded balloon with a tail (bottom-left / bottom-right). The tail inherits the fill — solid or gradient — and is included in the shadow.

Solid shadow

Use variant="sh(solid)" for a hard offset shadow — like the tactical speech balloons (drop-shadow(.5em .5em 0 #000)). Tune with --ui-sticker-shadow-x/-y/-color.

Fit to width (text-fit)

Use variant="fit" to grow each line element to fill the box width with native text-fit — no overflow, no SVG/JS. fit(shrink) shrinks overlong lines. Progressive enhancement (Chrome 150+); elsewhere the cqi sizing is the fallback.

Text sticker

Use variant="text" for puffy "sticker lettering" — no box, just glyphs with a thick white stroke (the puff), a solid colored fill and a colored keyline. The fill comes from color/theme. Pick a font with text(industrial|slab|antique|handwritten) (modern font stacks, no webfont). Size via --ui-sticker-text-size.

Glass (on product images)

Use variant="glass" for a frosted, semi-transparent badge that reads well over any photo. It tints with the system Canvas/CanvasText colors (auto light/dark) and blurs the image behind. Add color/theme to tint the frost. Shown on image-only <ui-card>s, positioned with the card's sticker(te) token.
