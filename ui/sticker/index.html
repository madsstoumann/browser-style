CSS

CSS-first promotional callout. fill = background (ink auto-contrasts), ink = text color, size = box scale. CSS-only — there is no JavaScript version: index.js exists purely so import '@browser.style/sticker' resolves; it registers the tag and adds no behaviour.

Variants

The default is a disc; set variant = burst, spark, sunburst, heart, blob, speech(l|r), text or clip (custom shape via --ui-sticker-clip-path).

Glass — theme="… glass"

glass is a material, not a colour — it needs something behind it, so these sit on a photo. Without a colour token it is a neutral frost; pale first gives the gentlest tint. The sticker's own box is the plate, so the fill and the backdrop blur land together.

Ink is pinned with ink= rather than left to the theme: over a translucent pane the glass ink (the hue itself) drops to ~2:1 against the composited disc. A four-character lead also needs font-lead="sm" so it clears the circle's edge.
