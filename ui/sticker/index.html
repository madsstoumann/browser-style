UI: Sticker

CSS

<ui-sticker> is a CSS-first promotional callout — a round disc by default, or a 24-point starburst with variant="burst". Use color for semantic colors and size for scale.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version.
