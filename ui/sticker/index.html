UI: Sticker

CSS

<ui-sticker> is a CSS-first promotional callout — a round disc by default, or a shape via variant (burst, spark, sunburst, heart, blob, speech(l|r), text). Use fill for any single background color (ink auto-contrasts), ink to set the text color explicitly, and size for the box scale.

This page demonstrates the CSS-only approach (no JavaScript). See the web component demo for the JS-enhanced version.

Variants

The default is a disc; set variant = burst, spark, sunburst, heart, blob, speech(l|r) or text.

Sizes & shadow

The size attribute scales the box (sm, md, lg default, xl, 2xl, 3xl); element lines follow via cqi. Here each step also takes a matching soft shadow (sm…2xl, via filter: drop-shadow()) so the elevation grows with the sticker. They also carry font="tsh(md)" — a cqi text-shadow that scales with the text.

Solid shadow

Use shadow="solid" for a hard offset shadow — the tactical/comic look. Step the offset with off(sm|md|lg), or -off(…) to throw the shadow to the left (the speech-left balloon below). Here every sticker shares one .sh-tint class that sets --ui-sticker-shadow-color to a near-black color-mix() of its own fill — so each shadow is a dark version of its sticker. The same shape set as above; drop-shadow() follows every clipped outline.

Gradient (custom class)

Gradients are a custom class that sets --ui-sticker-bg (and --ui-sticker-c, since contrast-color() can't read a gradient). Give the lead line its own color with --ui-sticker-lead-c for a two-tone callout. See the .grad-* classes in this page's <style>. Works on discs and clipped shapes alike.

Text sticker

Use variant="text" for puffy "sticker lettering" — no box, just glyphs with a thick white stroke (the puff), a solid colored fill and a colored keyline. The fill comes from fill. Set the typeface with the font attribute or a custom class that sets --ui-sticker-font-family (here the .font-* classes) — a fat, rounded display face holds the puff best. Tilt with angle, size via --ui-sticker-text-size.

Hover

Opt-in hover effects via the hover attribute (composable): lift, pop, tilt / -tilt (either direction), spin / -spin (one turn, either direction), press (on click). Hover the stickers below. A sticker is pointer-events: none until hover is set, so it never blocks an underlying link. Honors prefers-reduced-motion (movement drops).

Fit to width (text-fit)

Use font="fit" (and/or font-lead="fit") to grow each line element to fill the box width with native text-fit — no overflow, no SVG/JS. Each line is its own single-line element, so each fills its column independently. Progressive enhancement (Chrome 150+); elsewhere the cqi sizing is the fallback.
