UI: Sticker

CSS

<ui-sticker> is a CSS-first promotional callout — a round disc by default, or a shape via variant (burst, spark, sunburst, heart, blob, speech(l|r), text). Use fill for any single background color (ink auto-contrasts), ink to set the text color explicitly, theme for preset bundles, and size for the box scale.

This page demonstrates the CSS-only approach (no JavaScript). See the web component demo for the JS-enhanced version.

Shapes

Use variant = burst, spark, sunburst, heart or blob. variant carries the shape only — every other knob is its own attribute.

Each line is a semantic element — <small> for a label, <strong> for the lead — with preset cqi sizes, so no inline font-size is needed and the text scales with the box.

Sizes

The size attribute scales the box (sm, md, lg default, xl, 2xl, 3xl); element lines scale with it via cqi. These also carry font="tsh(md)" — a cqi text-shadow (tsh(sm)…tsh(xl)) that grows with the text.

Shadow

Use the shadow attribute: sm…2xl for soft elevation, or solid for a hard offset (tune the offset with off(sm|md|lg)). It uses filter: drop-shadow() so it follows clipped star/heart shapes too.

Theme

Use theme for a decorative color bundle (background + ink), distinct from the fill/ink axis. If both are set, theme wins.

accent dark subtle green

Multi-line

Each direct child is its own line; use gap="sm|md|lg" for line-spacing. <small> (label) and <strong> (lead) give preset, fluid cqi sizes — no inline styles.

Speech balloon

Use variant="speech(l)" or speech(r) for a rounded balloon with a tail (bottom-left / bottom-right). The tail inherits the fill — solid or gradient — and is included in the shadow.

Solid shadow

Use shadow="solid" for a hard offset shadow — like the tactical speech balloons (drop-shadow(.25em .25em 0 #000)). Add off(sm|md|lg) to step the offset, or tune --ui-sticker-shadow-x/-y/-color directly.

Fit to width (text-fit)

Use font="fit" (and/or font-lead="fit") to grow each line element to fill the box width with native text-fit — no overflow, no SVG/JS. Each line is its own single-line element, so each fills its column independently. Progressive enhancement (Chrome 150+); elsewhere the cqi sizing is the fallback.

Text sticker

Use variant="text" for puffy "sticker lettering" — no box, just glyphs with a thick white stroke (the puff), a solid colored fill and a colored keyline. The fill comes from fill/theme. Set the typeface with the font attribute or a custom class that sets --ui-sticker-font-family (here the .font-* classes) — a fat, rounded display face holds the puff best. Tilt with angle, size via --ui-sticker-text-size.

Glass (on product images)

Use the glass attribute for a frosted, semi-transparent badge that reads well over any photo. It tints with the system Canvas/CanvasText colors (auto light/dark) and blurs the image behind. Add fill/theme to tint the frost. Shown on image-only <ui-card>s, positioned with the card's sticker(te) token.
