UI: Lightbox

CSS

<ui-lightbox> is a "view gallery" / fullscreen toggle. It wraps an invoker <button command="toggle-popover" commandfor="<frame id>"> and a <ui-icon type="grid">. Pointed at a <ui-media popover> frame, the button lifts the frame into the top layer — the platform's built-in toggle-popover command needs no JavaScript. The full gallery presentation (fullscreen carousel/grid, backdrop, furniture hiding) lives in the card system: see ui/card/media.lightbox.html.

The component itself is CSS-only. index.js registers the tag and adds no behaviour; the optional command.js adds the in-lightbox layout toggle (--lightbox-layout), [open] reflection, and a click fallback for browsers without native command= invokers.

Idle / open (grid glyph morphs to ×)

Sizes

Use the size attribute: sm, lg, xl (md is the default). In a card: lightbox(sm) etc.

Hues, disc shape, bare glyph

Nine hues via theme= (in a card: lightbox(blue)); disc via radius="sqr|rnd|crc"; variant="non" for a bare glyph.
