UI: Components

Marquee

<ui-marquee> scrolls its content across a clip viewport. Put all content in a single child (the track) — text, logos, images or chips. Zero JavaScript. Pauses on hover/focus; add paused to stop.

Default — fade before repeat (scrolls left)

<ui-marquee>

Content fully clears before the loop repeats, at any length. Works in all modern browsers.

Loop — never-ending text (all browsers)

Seamless continuous text: the phrase re-appears with no fade. Repeat the phrase to fill the frame, then duplicate the whole run (2nd copy aria-hidden); the track shifts by exactly −50%.
