Marquee

<ui-marquee> scrolls its content across a clip viewport. Put all content in a single child (the track) — text, logos, images or chips. Zero JavaScript. Pauses on hover/focus; add paused to stop.

Default — fade before repeat (scrolls left)

Seamless testimonial cards

variant="cards seam fade" direction="right" style="--ui-marquee-item-size:22rem;--ui-marquee-visible:3"

cards switches the item shape: instead of a max-content nowrap text run, each direct child becomes a fixed track cell that wraps normally. It deliberately sets no display — the child keeps its own, so a <ui-card> stays a grid no matter which sheet loads last. Combine it with any mode; seam gives the gap-free loop and fade the edge mask.

The cards are the Testimonial shape — a Review of an Organization, which is what a testimonial is in schema.org (there is no Testimonial type). Full microdata, no type chip, no per-card style.

Loop — never-ending text (all browsers)

variant="loop" theme="red" font="bold"

Seamless continuous text: the phrase re-appears with no fade. Two identical direct children (2nd copy aria-hidden), each shifted by exactly −100% of its own width. Or skip the markup entirely with aria-label (below).
