UI: Chip

CSS

<ui-chip> is a CSS-first chip component for tags, labels, filters, and status indicators. It's visually aligned with <ui-button> and shares the same color and spacing tokens. Use color for semantic colors, size for scale, and variant for style (light, outline, square, squircle).

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version.
