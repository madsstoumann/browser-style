UI: Chip

CSS

<ui-chip> is a CSS-first chip component for tags, labels, filters, and status indicators. It's visually aligned with <ui-button> and shares the same color and spacing tokens. Use theme for a named hue, fill/ink for an arbitrary colour, size for scale, and variant for style.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version.

Sizes

Use the size attribute: sm, lg, xl, 2xl (md is the default). Sizes are em-based, so they scale with the surrounding text.

Small Medium Large X-Large 2X-Large

Theme

Use theme for a named hue bundle (background + ink). For arbitrary colours use fill (auto-contrast) + ink.

red orange green blue accent white gray slate black

Modifiers compose on a colour: pale (tint), muted (fade), light/dark (color-scheme).

red red pale red muted red pale muted

Corners — radius

Default is pll (pill). Use radius="non|rnd|pll|crc|sqr": non sharp, rnd rounded, crc circle, sqr squircle (iOS-style superellipse). Same values as the card token chip(<corner>) and the other furniture.

non rnd pll (default) crc sqr
