UI: Chip

CSS

<ui-chip> is a CSS-first chip component for tags, labels, filters, and status indicators. It's visually aligned with <ui-button> and shares the same color and spacing tokens. Use theme for a palette colour, fill/ink for an arbitrary colour, size for scale, and variant for style.

<ui-chip> is CSS-only — there is no JavaScript version. index.js exists purely so import '@browser.style/chip' resolves; it registers the tag and adds no behaviour, and the component is identical without it.

Sizes

Use the size attribute: sm, lg, xl, 2xl (md is the default). Sizes are em-based, so they scale with the surrounding text.

Small Medium Large X-Large 2X-Large

Theme

Use theme for a palette colour: <hue>-<step> (red-700, gray-200), or white / black. Background and ink come as a pair, so every step carries a readable label. For arbitrary colours use fill (auto-contrast) + ink.

red-700 orange-400 green-800 blue-900 accent-700 white gray-200 gray-700 gray-800

A lighter or darker step is the tint or the fade; modifiers compose on a colour: glass (material), ink, light/dark (color-scheme).

red-700 red-300 red-200 red-100

glass is a material, not a colour — it needs something behind it, so these sit on a photo. Without a colour token it is a neutral frost.

glass red-200 glass green-100 glass blue-100 glass border

Corners — radius

Default is pll (pill). Use radius="non|rnd|pll|crc|sqr": non sharp, rnd rounded, crc circle, sqr squircle (iOS-style superellipse). Same values as the card token chip(<corner>) and the other furniture.

non rnd pll (default) crc sqr
