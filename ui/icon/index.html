UI: Components

Icon

<ui-icon> is a CSS-first icon component built entirely with pseudo-elements and CSS transforms. No SVG sprites, no icon fonts, no JavaScript required. Use the type attribute for shape, size and stroke for dimensions, and variant="rounded" for soft line caps.

Icons animate automatically when inside an [open] parent (e.g. <details>) or next to a :checked input. See the state transitions section below.
