UI: Components

Icon

<ui-icon> is a CSS-first icon component built entirely with pseudo-elements and CSS transforms. No SVG sprites, no icon fonts, no JavaScript required. Use the type attribute for shape, size and stroke for dimensions, and variant="rounded" for soft line caps.

Icons animate automatically when inside an [open] parent (e.g. <details>) or next to a :checked input. See the state transitions section below.

Shapes

Use type=shape with a shape="bookmark|heart|star" and optional variant=outline.

Variant: rounded

Adds rounded line caps to line-based icons. Shown at size="2xl" to highlight the effect.

Chevrons and arrowheads use CSS borders (two sides of a rotated box), so their endpoints cannot be rounded with border-radius. Only line-based icons (plus, minus, cross, menu bars, arrow shafts) are affected.

Size

Use the size attribute: xs, sm, md, lg, xl, 2xl.

Stroke

Use the stroke attribute: xs, sm, md, lg, xl.

Variant: border

Wraps each glyph in a ring/badge. Shape follows --ui-icon-radius (a circle by default).
