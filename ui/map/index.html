UI: Components

Map

<ui-map> draws an interactive map on keyless OpenStreetMap-family raster tiles, clustering its points with Supercluster via Leaflet. It is configured by the map= token DSL, and it reads its points from the microdata already on the page — there is no second copy of the data, so a pin and its machine-readable value cannot drift.

Inside a card, put it in <ui-media>. For a single, static point you do not need this element at all — an OpenStreetMap <iframe> is enough, and the frame already sizes it: see ui/card/docs/media.md § Map.

Clustered, fitted to its points

map="tiles(auto) cluster fit" — zoom in and the clusters split.

tiles() — six keyless basemaps

positron, dark and voyager are the raster twins of the openmaptiles.org styles of the same names. tiles(osm) is dev/self-host only — see the readme.

tint() — pure CSS, composes with any basemap

One filter on the tile pane, so it costs no extra request and works on every tiles() value.

pin() — the single-point look

A cluster is always a count bubble; pin() picks how an individual point draws. Zoom in to see them.

ctl() and scroll

Wheel zoom is off by default — a map embedded in a page must not swallow the page scroll. The attribution control is not spellable in the DSL: every tile licence here requires it.
