UI: Components

Video Embed

Video Embed is a container that holds a video player and a preview image. The user can click the play button to start the video. The component is the same in opposite color-scheme and right-to-left.

YouTube lite-embed on <ui-media>

The frame is a plain <ui-media provider="youtube" video="ID"> — it owns the aspect-ratio (asr()), corners (rds()) and the 3×3 grid that positions the <ui-play> control (play(cc)). The poster is derived from the video id; a nested <ui-play> targets the frame through the native Invoker Commands API (command="--toggle-play" commandfor). The controller defers the YouTube iframe until that first click, then hands off to the player's own controls. No layout of its own.
