UI: Save

CSS

<ui-save> is a CSS-first favorite / wishlist / bookmark toggle. State is handled entirely by a wrapped checkbox — no JavaScript needed. Use icon for the glyph and size for scale.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the registered-element version.

Basic — heart (default)

Icons

Use the icon attribute: heart (default), bookmark, star.

Sizes

Use the size attribute: sm, md (default), lg.

Theme

Use theme for a decorative ink color from a bundle. Save is icon-only, so only the bundle's ink (c) tints the idle glyph.

Custom tokens

Override --ui-save-c-active and --ui-save-sz.
