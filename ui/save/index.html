UI: Save

CSS

<ui-save> is a save / favorite / wishlist / bookmark toggle. It wraps an invoker <button command="--save"> and a <ui-icon type="shape">. The button's aria-pressed drives the look: unsaved = outline, saved = filled — in the same ink, since --ui-save-c-active defaults to --ui-save-c. Flipping aria-pressed is wired in script via the invoker command (not shown here).

The component itself is CSS-only — there is no JavaScript version. index.js exists purely so import '@browser.style/save' resolves; it registers the tag and adds no behaviour.

Unsaved / saved (heart, default)

Two-colour toggle — --ui-save-c-active

One ink is the default. For the classic neutral outline → red fill, set the active ink per instance: style="--ui-save-c-active: var(--color-error)".

Click feedback — hover=

Opt in to motion with the hover attribute (like ui-sticker): press scales down while you hold the click, pop scales up on hover. Combine them (hover="press pop"). Tokens: --ui-save-hover-press / -pop / -duration / -ease.

Shapes

Any ui-icon shape works: heart (default), bookmark, star.

Sizes

Use the size attribute: sm, lg, xl (md is the default).

Outline width

The outline is a real border on the glyph, and its thickness follows the size: --ui-save-stroke is 0.1em, not the absolute 2px ui-icon defaults to — that one reads right at md, chunky at sm and thin at xl. Unsaved glyphs across the size scale, same relative weight:

Retune globally or per instance with the token — style="--ui-save-stroke: 0.05em" for a hairline, 0.2em for a heavy outline (both still scale with size=):

Without the circle — variant="non"

The circle backdrop is on by default. Add variant="non" for a bare glyph (in a card: save(non)). Retune the disc via its tokens (--ui-save-circle-bg / -border-color / -shadow).

Disc shape — radius=

The circle disc can be reshaped: crc (default circle), sqr squircle, rnd rounded square. (variant="non" hides it entirely.) In a card: save(sqr) etc.
