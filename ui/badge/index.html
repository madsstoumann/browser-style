UI: Badge

CSS

<ui-badge> is a CSS-first badge component for status indicators and notification counts. It positions itself at a corner of its parent (avatar, button, chip, etc.) or can flow inline as a label. Use color for semantic colors, size for scale, position for corner placement, and variant for shape and inline behavior.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version.

Basic

The badge positions itself at the top-right corner of its parent. The parent automatically gets position: relative. Circular <ui-avatar> parents are auto-detected and the badge is inset to sit on the arc.

Positions

Use position: top-right (default), top-left, bottom-right, bottom-left.

Host shape: circle

Add host-shape="circle" when the badge's parent is circular so it sits on the arc (offset inward by ~14.6%) instead of floating outside the visible circle. For <ui-avatar> parents, this is applied automatically.
