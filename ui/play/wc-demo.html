UI: Play

Web Component — generic play/pause

<ui-play> is a target-agnostic play/pause button. It reflects state to aria-pressed (inner button) and open (host) — the latter morphs a <ui-icon type="play-pause"> glyph via CSS. It drives targets through the native Invoker Commands API (command + commandfor on the button); with no commandfor it emits a bubbling ui-play-toggle event instead (the contract the carousel uses). for remains a shorthand for a <video>.

Toggle (no target — emits ui-play-toggle)

Click to toggle. The glyph morphs play↔pause; the event log updates.

No events yet.

Command — control a <video>

The button carries command="--toggle-play" commandfor="cmd-video". The delegated controller (command.js) plays/pauses the video and reflects its real state back (try the native controls too).

Command — pause a CSS animation

Same button, commandfor="anim-box". The controller toggles animation-play-state on the target.

Shorthand — for a <video>

Without commands: for="for-video" binds a <video> directly.
