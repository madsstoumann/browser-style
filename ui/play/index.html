UI: Play

<ui-play> is a CSS-first, target-agnostic play/pause button — a single <button> wrapping a <ui-icon> glyph. As a web component it drives any target through the native Invoker Commands API (command + commandfor) and reflects state to aria-pressed + open. With type="play-pause" the glyph morphs between the two states via an animated clip-path (driven by open on the host) — no icon swap.

See the web component demo for <video> control, the ui-play-toggle event, and the for shorthand.

Play/pause morph — the clip-path animation

The glyph is a single <ui-icon type="play-pause">. Toggling the button flips open on the host, and CSS morphs the glyph between the play triangle and the pause bars. The first button has no target (pure morph); the others start and pause a bouncing box's animation-play-state via command="--toggle-play" commandfor — click play to start the bounce.

Variants & styling

Solid (default)

Playing state (pause glyph)

Author <ui-icon type="pause"> to show the pause glyph. (CSS-only here; the web component swaps the icon type and toggles aria-pressed for you.)

Always visible vs. reveal on hover

The reveal variant stays hidden until the parent media frame is hovered or focused.

Sizes

Use the size attribute: sm, md (default), lg, xl.

Theme

Use theme for a decorative color bundle (bg + ink).

Custom tokens

Override --ui-play-bg, --ui-play-c, --ui-play-sz, and --ui-play-icon-sz.

Brand shapes

Use variant="youtube" or variant="vimeo" to reshape the disc into a platform badge, keeping the white play arrow. YouTube is a red squircle via corner-shape: superellipse() (degrades to plain rounded corners where unsupported); Vimeo is a cyan disc; rounded(sm|md|lg) clips the disc into a play triangle with scalable corner rounding via clip-path: shape(). Override color with --ui-play-bg / --ui-play-bg-hover, corners with --ui-play-radius / --ui-play-corner, the path with --ui-play-shape.
