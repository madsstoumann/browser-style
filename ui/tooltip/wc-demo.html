UI: Components

Tooltip — Web Component

Using <ui-tooltip> as a registered custom element. The JS adds role="tooltip", aria-describedby wiring on the parent, and ESC-to-dismiss. All visual behavior is CSS-driven.

Avatars (size="match")

Press ESC to dismiss

The web component listens for the Escape key and sets [hidden] on the tooltip. Hover or focus the parent again to re-show.
