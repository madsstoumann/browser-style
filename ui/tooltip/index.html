UI: Tooltip

CSS Only

<ui-tooltip> is a CSS-first speech-bubble tooltip drawn as a single element via clip-path, so backgrounds (including gradients) flow seamlessly across the bubble and arrow. Drop it as a child of any focusable element. The parent automatically gets position: relative; the tooltip shows on hover or keyboard focus.

This page demonstrates the CSS-only approach (no JavaScript). See the web component demo for the JS-enhanced version with ARIA wiring.

Basic

The default position is top. Hover or tab to the buttons.

Positions

Use position: top (default), top-start, top-end, bottom, bottom-start, bottom-end.

Colors

Use the color attribute for semantic colors: info, success, warning, error.

Gradient backgrounds

Because the bubble and arrow share one element, a gradient flows seamlessly across both.

Sizes

Use the size attribute: sm, md (default), lg, match. The match size scales with its container's inline size (uses container query units).

The match size scales with the trigger — perfect for avatars, where the tooltip should shrink for tiny avatars and grow for large ones:

AB Anna Berg LP Linda Payne JD John Doe GH Greg Hanson KC Kim Cronos

Multiline / wrapping

Add variant="multiline" to allow wrapping. Set --ui-tooltip-max-width to control the max width.

No arrow

Add variant="no-arrow" for a plain rounded rectangle (no speech-bubble tail).

Inline help in body text

Use variant="underline" or variant="overline" to style the parent element with a dotted text decoration and help cursor — perfect for inline help text inside paragraphs.

The display uses OLED panels Organic Light-Emitting Diode for true blacks. The GPU Graphics Processing Unit — handles all visual rendering can also be used for compute workloads General-purpose parallel computation via CUDA, Metal, or WebGPU .

Or use variant="help" alone for just the help cursor without any text decoration:

Delay

Use delay: none, short (default ~100ms), long (~400ms).
