Staggering a row — --ui-beacon-delay

Each animation shorthand takes --ui-beacon-delay (default 0s), so a row can be offset without touching the durations. The row above uses it; here it is on its own, with a wider beat: 

.stagger ui-beacon { --ui-beacon-delay: calc((sibling-index() - 1) * 0.3s); }

<p class="stagger">
  <ui-beacon variant="solid">1</ui-beacon>
  <ui-beacon variant="solid">2</ui-beacon>
</p>

Theme modifiers

The shared theme= axis takes a lighter or darker step for a tint or a fade, and carries light and dark.

Arbitrary colors — fill= / ink=

fill sets the accent (dot, solid plate, ticker panel); the plated faces derive a readable label with contrast-color(). ink overrides that derived label.

Violet dot  Violet pill  Auto ink  Auto ink  Gold ink

Corners — radius=

rnd rounded · sqr squircle · pll fully rounded. Applies to the plated faces. (non is not part of this axis — beacon spends it on animation-off.)

default  rnd  sqr  pll

Glass — theme="… glass"

glass is a material, not a colour — it needs something behind it, so these sit on a photo. Without a colour token it is a neutral frost.

Use it on the plate variants (pill, solid, ticker), which paint a box the material can fill. The bare dot draws itself in ::before and has no plate, so glass there blurs the host's square box behind a tiny dot — colour it with a hue instead.
