UI: Avatar

CSS

<ui-avatar> is a CSS-first avatar component. Place an <abbr> for initials and/or an <img> inside it. Each avatar gets a unique random background color with auto-contrasting text. Wrap multiple avatars in <ui-avatar-group> for stacked or spread layouts with overflow counting.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version with framework-friendly overflow handling.

Ring

Use the ring attribute for an activity ring. Accepts a semantic keyword (error, info, success, warning), a custom color value, or defaults to the accent color.

You can also use custom properties: --ui-avatar-ring (for gradients), --ui-avatar-ring-width, and --ui-avatar-ring-offset (gap).

Combined: ring, status and badge

Avatars compose cleanly with <ui-badge>. Add a badge as a child — circular avatars automatically inset the badge to sit on the arc (see the badge docs for details).

Status lives at the bottom-right of the avatar, so badges should use top-right (default), top-left, or bottom-left to avoid clashing with it.
