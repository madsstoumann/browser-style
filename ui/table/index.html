UI: Table

CSS

Table is a CSS-first styling system for native <table> elements. Each feature is an attribute — compose them freely on the table, its rows, or a wrapping <ui-table-wrapper>. Light/dark mode, RTL, and touch-safe hover come for free.

This page demonstrates the CSS-only approach (no JavaScript).
See the web component demo for the JS-enhanced version using <ui-table>.

Thead divider

Opt into a stronger border between the <thead> and the first <tbody> row. Width and style are independent variants that compose: widths th-divide-lg / th-divide-xl; styles th-dotted, th-dashed, th-double, th-groove, th-ridge. Any one activates the border; unset pieces fall back to thick / solid. th-double, th-groove, and th-ridge auto-force the width they need to render (double: 4px, 3D: 6px).

Graduated tint

Wire up @browser.style/base's generic tint system. data-tint on the table sets the ramp's start color; data-tint-end (optional) sets the end color (defaults to white). Where you put tinted — and what value it carries — chooses the direction:

  • <tbody tinted> — vertical ramp across rows
  • <colgroup tinted> — horizontal ramp across columns
  • <tbody tinted="2d"> — bilinear 2D ramp across cells; opt into the extra corners with data-tint-tr (top-right) and data-tint-bl (bottom-left), or omit them and get a clean diagonal mid-mix

When the table carries data-tint and has a tinted descendant, two extras kick in: the <thead> is painted with the start color (in 2D mode it ramps horizontally with the top edge), and the cell borders adopt a tint-blended color instead of the default gray. Text contrast on every row/column/cell is automatic via contrast-color().

Section / group headers

Add data-row="group" to a <tr> containing a single <td colspan="N"> to turn it into a section heading: semibold text on a tinted background, drawn inside <tbody> like any other row. Compose with a status variant (data-row="group error", data-row="group info", …) to tint the heading with a semantic color. Because data-row uses ~= word-matching, the values compose freely.

Overflow wrapper

Wrap a table in <ui-table-wrapper> — scrollable container, sticky <thead>. Opt into sticky columns with data-sticky="c0 c2 c4" (0-indexed) and pin each one via --c0, --c2, --c4. Each value is the sum of the sticky column widths before it — non-sticky columns scroll away, so they don't count. Here col 0 pins at 0, col 2 at col 0's width (100.59px), and col 4 at col 0 + col 2 (234.79px). See the readme for details.
