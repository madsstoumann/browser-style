UI: Table

CSS

<ui-table> is a CSS-first scroll wrapper for native <table>. Compose layout via data-variant (rounded, split-cols, split-rows, th-dark, th-light, thead-divider family, zebracol-*, zebrarow-*, no-border, no-wrap, fixed); density via data-size; per-row state via data-row; per-column alignment / tabular figures via data-cN; hover effects via data-hover; graduated tints via data-tint + tinted. Add frame to the wrapper for a framed scroll container with sticky thead, sticky group rows, and opt-in sticky columns via data-sticky.

This page demonstrates the CSS-only approach.

See the web component demo for the JS-enhanced version using <ui-table>, and the readme for full documentation.

Graduated tint
