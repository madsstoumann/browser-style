UI: Table

CSS

Table is a CSS-first styling system for native <table> elements. Each feature is an attribute — compose them freely on the table, its rows, or a wrapping <ui-table-wrapper>. Light/dark mode, RTL, and touch-safe hover come for free.

This page demonstrates the CSS-only approach (no JavaScript). See the Web Component section for the JS-enhanced <ui-table>.

Section / group headers

Add data-row="group" to a <tr> containing a single <td colspan="N"> to turn it into a section heading: semibold text on a tinted background, drawn inside <tbody> like any other row. Compose with a status variant (data-row="group error", data-row="group info", …) to tint the heading with a semantic color. Because data-row uses ~= word-matching, the values compose freely.

Overflow wrapper (CSS-only)

Zero JavaScript. <ui-table-wrapper> (an un-registered custom element, styled purely via CSS) turns its child table into a scrollable container with a sticky <thead> and optional sticky columns. Two scroll-driven animations (animation-timeline: scroll(self inline) + scroll(self block)) flip the --_has-overflow flag when the content actually overflows on either axis — that gates the wrapper frame and collapses the inner table's edge borders. Sticky columns are declared via data-sticky="c0 c2" (0-indexed); the pin positions come from --c0, --c2, which you measure once in devtools and hard-code. In this demo "First Name" renders at ~101px wide, so "Known As" pins at --c2: 101px — flush against col 0. Safari (no scroll-driven animations yet) falls back to a manual overflowing attribute, which the <ui-table> web component toggles automatically.

Overflow with auto-detection

A wide table inside <ui-table overflow> reveals the scrollable wrapper (with sticky header and optional sticky columns via sticky="c0 c2") when it overflows the viewport. The script sets cumulative widths as CSS custom properties (e.g. style="--c0: 0px; --c2: 36px;") so sticky columns pin at the correct positions. Resize the window to see the responsive behavior.
