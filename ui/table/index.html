UI: Table

CSS

Table is a CSS-first styling system for native <table> elements. Use data-variant for layout (density, borders, split layouts, zebra striping, dark/light header) and data-hover for interactive hover effects on columns, cells, rows, and headers.

This page demonstrates the CSS-only approach (no JavaScript). See the Web Component section for the JS-enhanced version using <ui-table>.

Overflow wrapper

A wide table inside <ui-table overflow> reveals the scrollable wrapper (with sticky header and optional sticky columns via sticky="c0") when it overflows the viewport. The script sets cumulative widths as CSS custom properties (e.g. style="--c0: 0px; --c2: 36px;") so sticky columns pin at the correct positions. Resize the window to see the responsive behavior.
