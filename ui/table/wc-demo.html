UI: Table

Web Component

<ui-table> forwards variant, hover, size, and sticky attributes to the child <table> as data-* attributes. Add frame to upgrade from a bare scroll container to the full framed mode; in that mode a ResizeObserver observes its own size, toggles the overflowing attribute as a Safari ≤ 18 fallback, and walks the sticky list to compute cumulative column widths as --cN custom properties. See the CSS-only demo for the non-JS version.

Overflow with auto-detection

A wide table inside <ui-table frame> activates the framed scrollable wrapper when it overflows the viewport. Unlike the CSS-only version, you don't hard-code --cN values: pass sticky="c0 c2 c4" and the script measures each sticky column's rendered width on resize, setting the cumulative offsets for you. Resize the window to see the responsive behavior.
