UI: Table

Web Component

JS behaviour gates on two opt-in attributes:

  • mount — attribute forwarding only. Forwards variant, hover, size, sticky, the tint* family (tint, tint-end, tint-tr, tint-bl), and c1…c8 to the inner <table> as data-*. Use for framework-binding on a visually plain scroll container.
  • frame — framed scroll-container mode. Implies mount, plus runs a ResizeObserver that toggles overflowing (Safari ≤ 18 fallback) and walks sticky to compute cumulative column widths as --cN custom properties.

Bare <ui-table> (neither attribute) is inert — CSS-only scroll container, no JS.

See the CSS-only demo for the non-JS version, and the readme for full documentation.

Overflow with auto-detection

A wide table inside <ui-table frame> activates the framed scrollable wrapper when it overflows the viewport. Unlike the CSS-only version, you don't hard-code --cN values: pass sticky="c0 c2 c4" and the script measures each sticky column's rendered width on resize, setting the cumulative offsets for you. Resize the window to see the responsive behavior.
