UI: Components > FormEmbed

<form-embed> loads a published form by id (a bundle of form, rules and the names of the functions it needs) and renders it with <form-flow>. This page does not load @browser.style/base: it plays a client site, with a serif font and hot-pink dashed inputs of its own.

Shadow DOM (default)

The site's input rules stay out; the font and colour are inherited.

Shadow DOM, branded

The same mode, themed with --form-* custom properties and ::part(). The loan form names three host functions (cprDate, dk-cpr, dk-cvr), loaded from the registry. Try CPR 070761-4285.

Light DOM

With mode="light" the form is in the page, so the site's own CSS applies (here, a green border beats the form styles); the form styles stay inside @scope (form-embed) and do not touch the inputs below.
