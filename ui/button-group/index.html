Button Group

A button group is a set of buttons that are visually grouped together. Button groups are used to group related buttons together, making it easier for users to find and interact with them.

Note, that the border-width is 0.125em — every metric here is em by design, so one size= (or one font-size) sizes the whole control. Don't "fix" it into --border-width-thick, which is absolute. Overwrite with --ui-button-group-border-width.


The <ui-button-group> host

Wrap the <fieldset> in <ui-button-group> to write the bare attributes — variant, theme, size — the way every other component in the set does. The element wraps the fieldset rather than replacing it (the same shape as <ui-accordion> around its <details>), so native radio grouping, <legend> labelling and fieldset[disabled] propagation all survive. It is display: contents, so it adds no box and renders identically to the class form.

Sizes

size="xs sm md lg xl 2xl" — the same em ladder as Chip and Beacon, defaulting to 1em (a control is a hit target sized to its context, where a chip sits smaller than its surroundings). Because the value is em, the ladder composes: a size="sm" group is 0.625× whatever text surrounds it.
Note, base's fs-* utilities still work and still win, but they are CSS absolute-size keywords — an fs-sm group measures 13px whatever it sits inside. Pick one axis.

Themed — the shared hue axis

data-theme="red" · data-theme="green pale" · data-theme="blue muted"
Note the data- prefix: a bare theme attribute is invalid on a <fieldset> — on the <ui-button-group> host above it is simply theme. The hue paints the checked segment, not the group's own box, so the group opts out of the resolver's universal paint. All nine hues work, and so do the pale / muted modifiers — see base/theme.md.
