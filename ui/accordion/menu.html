Mega-menu in a header

The "Nested as mega-menu" example from the accordion demo, placed in a <header> with a dummy logo. No JavaScript: a visually hidden — but accessible — checkbox toggles the menu on mobile (burger icon, top right). Below 650px, <auto-morph slide-from="right"> turns the menu into a full-viewport panel (100vw × 100dvh) that slides in from the right; unchecking slides it out again. Above 650px the menu is always visible as panel-style tabs and the toggle is hidden. The header is sticky; when it sticks, a scroll-state(stuck: top) container query fades in its background and shadow.
