UI: Accordion

CSS

<ui-accordion> is a CSS-first collapsible content panel built on native <details> and <summary> elements. Use the name attribute for exclusive open behavior, change layout with types like horizontal, slide, and split, and compose variants like bordered, breakout, divided, rounded and separate.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version using <ui-accordion-item>.

Stagger: per-child overrides + fade opacity

Per-child overrides on the shared stagger engine, read via typed attr(): data-stagger-index reorders the cascade, data-stagger-step paces a single child, and data-stagger="fde semi" fades in element by element from half opacity.

Reordered cascade (2, 1, 3)

Second to appear — although it is the first paragraph in the DOM, its data-stagger-index="2" puts it in the middle of the cascade.

First to appear — data-stagger-index="1" pulls it ahead of the paragraph above it.

Third to appear — data-stagger-index="3" keeps it last, exactly where the DOM would have put it anyway.

Per-child pace

Quick — data-stagger-step="0.02s" makes this child's whole delay tiny.

Default — no attribute, so this child paces off the shared --stagger-step.

Extremely slow — data-stagger-step="0.6s" scales this child's delay to 1.2s.

Fade in from half opacity

These lines fade in one after another — no movement, just opacity.

The semi modifier starts them at opacity: 0.5 instead of fully hidden.

Drop the modifier (or spell it full) for the default fade from opacity: 0.

Staggered panel content — data-stagger

Wrap panel content in a <div data-stagger> (shared engine in ui/base/stagger.css) — its children cascade in as the panel opens, while the panel's own block-size animation runs. Effect tokens: rise (default) · fall · lft · rgt · zom · blr · fde · shimmer (+ sweep). (Not for type="split"/type="horizontal" — those have their own panel choreography.)

Rise (default)

First paragraph rises in.

Then this one follows, one step later.

And a third completes the cascade.

Fall

Children drop down into place.

The vector is inverted — they descend instead of rising.

Same staggered timing, opposite direction.

Slide from the left

Children enter from the inline-start.

Same cascade, horizontal vector.

Driven by the shared --stagger-* tokens.

Slide from the right

Children enter from the inline-end.

Mirror of lft — they arrive from the other side.

Respects writing direction (RTL flips it).

Zoom

Children scale up into place.

No translation — each grows from 65% to full size.

A punchier entrance for shorter panels.

Unblur

Children sharpen into focus.

Blur + fade, no movement.

Reduced-motion users get everything instantly.

Fade

Children simply fade in.

Opacity only — no movement, scale or blur.

The most restrained of the seven tokens.

Shimmer

Nothing moves — the text itself lights up. A coloured band reads down the block one line at a time, the way an eye moves through a paragraph. No per-word markup, no text splitting: it just sets the text to display inline. That means one block of text per panel — for several children, use the sweep variant below.

Shimmer sweep — for several children

One band, crossing every line at once.

Children stay blocks and the band is tilted, so a whole box lights up together rather than being read through.

Layout is untouched, so any number of children is safe.

Icon Variants

The <ui-icon> in each <summary> animates automatically when its parent <details> opens. See the icon component for the full set of state-transition icons (plus-minus, plus-cross, chevron down, and more).
