UI: Accordion

CSS

<ui-accordion> is a CSS-first collapsible content panel built on native <details> and <summary> elements. Use the name attribute for exclusive open behavior, change layout with types like horizontal, slide, and split, and compose variants like bordered, breakout, divided, rounded and separate.

This page demonstrates the CSS-only approach (no JavaScript).

See the web component demo for the JS-enhanced version using <ui-accordion-item>.

Nested accordions

An accordion can contain another <ui-accordion> inside any panel. Each level keeps its own name so the open-state groups stay independent. The indent attribute on the outer accordion turns on a per-details staircase using sibling-index() times --ui-accordion-indent; inner accordions pick it up via inheritance.

Nested as mega-menu (tabs morph)

A two-level nested structure wrapped in <auto-morph render="tabs"> with tabs="panel expanded". Above 650px the outer renders as a panel-style tabs interface — clicking a tab opens its panel with every nested section fully expanded, mega-menu style. Below 650px it falls back to a collapsible nested accordion.
