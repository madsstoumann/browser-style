Breadcrumbs

Breadcrumbs are a secondary navigation aid that helps users understand where they are in relation to the rest of the site.

CSS-only (data-breadcrumbs)

The first example is the canonical form: it carries the schema.org BreadcrumbList microdata Google needs for the breadcrumb rich result. On this path the markup is hand-authored — CSS cannot add it. The variant examples below leave it out so the separator is the only thing that differs; copy the first one for real use. The <ui-breadcrumbs> web component emits it for you. See readme.md § Structured data.
