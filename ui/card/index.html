UI: Card

Every card composes <ui-media> + <ui-content> inside a <cq-box> grid layer. The media frame is configured with media=, the text column with content=, and the composition (arrangement, overlay, theme, corners) with variant=. No JavaScript.

Media overlays — chip & sticker

Overlay furniture lives inside <ui-media>; position and sub-theme come from the parent media= token (chip(<pos>) / sticker(<pos>), chip(<hue>)). <ui-chip> is a pill label; <ui-sticker> is a disc, or a starburst with variant="burst".

Video & multi-source scroller

<ui-media> accepts a <video> (native controls/poster) just like an image. Add media="nav" for multiple sources — a flex scroll-snap row. nav(non) leaves it a bare swipe scroller, no JS.
