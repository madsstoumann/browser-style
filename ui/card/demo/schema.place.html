UI: Card — Place map layers

The Place card on the schema.org page makes an OpenStreetMap embed its media frame. That embed takes a layer= string in its URL, which picks the basemap style — the same eight entries the layer switcher on openstreetmap.org offers. Every card below is that same card at the same coordinates; only layer= changes.

Six of the eight are embeddable. tracestracktopo and openmaptiles_osm are marked canEmbed-less in OpenStreetMap’s config/layers.yml, so the embed drops them and renders Standard instead — the last two cards are here to show exactly that.
