UI: Card — Place map layers

The Place card on the schema.org page makes an OpenStreetMap embed its media frame. That embed takes a layer= string in its URL, which picks the basemap style — the same eight entries the layer switcher on openstreetmap.org offers. Each card below pairs one layer with a place that shows off what it draws.

Six of the eight are embeddable, and those six are below. tracestracktopo and openmaptiles_osm are marked canEmbed-less in OpenStreetMap’s config/layers.yml, so the embed drops them and renders Standard instead.
