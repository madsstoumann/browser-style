UI: Card — Personal goals

schema.org has no Goal type — the honest fit for a personal goal is AchieveAction, "an incremental achievement". Each card below is one action: actionStatus says whether it is still running, object is a QuantitativeValue carrying the target, result a second one carrying the current value. The visible progress — a native <progress> bar or a <ui-progress-circular> ring — carries no microdata of its own; the machine numbers ride the hidden metas, so display rounding can never lie to a parser.
