UI: Card — direction

Regression target for the one logical position grid. Every family below uses the same cells (ts tc te · cs cc ce · bs bc be); an s cell must sit at the left edge in the LTR column and the right edge in the RTL column. Anything that stays put is a bug. The last two families are the scroll-edge fade (content="scr(x)" and <lay-out overflow="fade">): both resolve their gradient direction through the same --_dir-s/--_dir-e pair, so the faded edge must swap between the columns too — scroll each one to its start and the fade must sit on the trailing edge.
