UI: Card — Carousel Builder

Design a carousel by composing its media= token string live. Six slides — five images and one video — each carrying a --ui-carousel-thumb-url (for mrk(tmb)) and an aria-label (for mrk(lbl)), so every marker type has the data it needs. The generated attribute is shown below the stage; the whole line is select-to-copy.

Reference demos: carousel · token tables: carousel.md. Vertical (axis(y) + mrk(rail)) and multi-card lay-out[overflow] scrollers are out of scope here — see the main demo page.
