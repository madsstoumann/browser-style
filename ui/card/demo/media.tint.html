UI: Card — Media tnt() tint

Wash a <ui-media> image in a solid colour — brand or political red/blue — while keeping the photo's detail. A colour overlay (ui-media::before) is blended over the image with mix-blend-mode.

See also: media.html (the full <ui-media> reference)

Theme presets — tnt(<key>)

Named keys map to the 8 theme colours (mirrors chip(red)/sticker(blue)): red orange green blue accent dark light subtle.

tnt(red) tnt(orange) tnt(green) tnt(blue) tnt(accent) tnt(black) tnt(white) tnt(gray)

Custom colours & knobs

Bare tnt reads --ui-media-tint-color — any CSS colour (hex, oklch(), etc.). Tune strength with --ui-media-tint-opacity, or switch the blend with --ui-media-tint-blend (default color; try multiply / luminosity).

#6d28d9 oklch(.7 .2 350) opacity 0.55 #0d9488 teal

Rich gradients

--ui-media-tint-color is painted via background, so it accepts any <image> — linear, radial or conic gradients. With the color blend the image picks up a hue gradient (luminance from the photo, hue from the gradient).

linear rose→violet oklch 3-stop radial conic
