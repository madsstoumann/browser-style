UI: Media — Carousel

CSS-only <ui-media> carousel: a scroll-snap row with native ::scroll-marker dots + ::scroll-button() arrows, driven by a media= token string. Native in Chromium; elsewhere /ui/carousel/polyfill/carousel.js (JS off → plain swipe scroller).

Prefer to explore interactively? The carousel builder composes the token string live — marker types, positions, arrows, tones, autoplay. Any carousel here can also open fullscreen via a <ui-lightbox> popover toggle — see the lightbox page.

Labels — mrk(lbl)

mrk(lbl) renders each slide's aria-label as a text pill, styled with --ui-carousel-label-* custom properties. A long label set never spills past the frame — the group caps to the frame's inline size and scrolls (see below).

Squared pills, no group background (.label-square, mrk(te)); frosted-white capsule (.label-white, mrk(bs)):

Labels are text, so a long set outgrows any frame. The group caps to the frame's inline size and becomes its own horizontal scroller — and because ::scroll-marker-group is a scroll-target-group, the current label is scrolled into view for free. Twelve labels, unchanged markup:

Prefer the whole set visible at once? --ui-carousel-label-group-wrap: wrap swaps the scroller for a wrapping block — still capped to the frame's inline size, but it grows in the block direction, so it suits short label sets or a band placement rather than a narrow overlay (.label-wrap, same twelve labels):

Timeline — mrk(tml)

mrk(tml) turns the markers into a timeline: a dot per slide on one continuous rail, labelled with the slide's data-date. The aria-label stays the accessible name, so a node shows 2016 while a screen reader hears the whole entry. Slides are tag-agnostic — mix images, video and themed <ui-content> plates.

Grid pages, staggered

Each page is its own <lay-out> grid inside a stagger pages scroller — a whole grid reveals per snap. Below md (540px) the pages dissolve and every card becomes its own slide; narrow the window to watch the dot count jump.

Two channels — crd() + ani()

crd() animates the cards, ani() their content; both cascade. Default pacing (--stagger-step: 0.07s) and document order — the cascade is over almost as soon as the page snaps.

Autoplay & loop — auto() · loop

auto() advances on a timer (pausing on hover/focus); loop clones the end slides so wrapping is seamless.

Autoplay + pill timer

 loop

Seamless loop

Next past the last smooth-scrolls into a cloned slide, then invisibly resets — no jump.
