UI: Card — Schema.org

Every card type from the legacy content/card package, re-created with the modern engine: <ui-card> + <ui-media> + <ui-content>, with satellites <ui-chip>, <ui-sticker>, <ui-save>, <ui-reveal> and <ui-accordion>. Structured data is inline microdata (itemscope/itemtype/itemprop + hidden <meta> values) — no JSON-LD, no JavaScript.

The matching CMS content model is cms/baseline/models/card.schema.json: a structured envelope + schemaType discriminator + one details object per type. See also: cards.html · media.html · content.html.

Proposed data-part vocabulary

Rebuilding all 25 types needs a few parts <ui-content> does not style yet. This page uses them as a spec — they render with default typography until content.css catches up. Everything else reuses existing parts (meta for salaries/hours/dates, tags for skills/hashtags, byline for people, footer for totals).
