UI: Card — Render Engine

Every card on this page is built at runtime by render.js from the UCF data files in data/ — the envelope + details model defined in cms/baseline/models/card.schema.json. Each card references a preset from card.presets.json (model: card-preset) that owns the element attributes — swap the reference to restyle. Markup and microdata match the hand-authored reference in schema.html. All DOM is built with createElement/textContent — no innerHTML. Full docs: card.md.
