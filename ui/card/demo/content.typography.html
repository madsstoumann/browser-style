Complete type scale — raw <ui-content>

A full-width reference of the existing type system. Three parts: the independent headline ramp (hl()), the body ramp (scl()), and the per-part proportional stack. Only hl() has its own size steps — every other part rides the body size (--ui-content-fs) × a fixed factor.

3 · Per-part proportional stack

Every supporting part is a fixed multiple of the body size (--ui-content-fs) — so the whole block scales as one when you change scl(). Only hl() has independent size steps; these factors are not tokens, they are the built-in ratios. Shown here at scl(md):

4 · Relational scale — hl()/tx() × scl()

Size tokens name a step on a ladder, not an absolute stop. Without scl() they are fixed; with scl() the whole ladder shifts (scl(sm) −1 · scl(md) identity · scl(lg) +1 · scl(xl) +2, saturating at the ends). Same hl(2xl) tx(xl) tokens, three master steps:

hl(2xl) tx(xl) — no scl(): fixed

Headline at the 2xl stop

Summary at the xl body stop — the absolute clamps, exactly as named.

meta — rides the default body size

 scl(sm) hl(2xl) tx(xl) — shifted −1

Headline renders the xl stop

Summary renders the lg body stop — both kept their relative prominence, one step down.

meta — follows scl(sm)

 scl(lg) hl(2xl) tx(xl) — shifted +1

Headline renders 3xl

Summary renders the 2xl body stop (the ladder-headroom clamp above xl).

meta — follows scl(lg)

5 · Group sizes — eb() / tx() / mt()

All four families take a size arg. tx(<size>) sets the Body-group base (summary, list, quote, price…), eb()/mt() size their group at the same ladder step × the group's built-in factor. Sizes are relational, so they shift with scl() like everything else.

6 · Responsive relational — md:/lg:scl() × fixed size tokens

Resize the cards (drag the handle): the size tokens stay put in the markup while the responsive master step re-points the ladder per container width. First card: the mobile-first idiom — small type in a narrow container, stepping up at lg (44rem). Second card: base hl(2xl) with md:scl(lg) — the unprefixed headline token re-resolves against the md: ladder (2xl → 3xl at 25rem).

scl(sm) lg:scl(md) hl(2xl) tx(xl)

Steps down when narrow

Narrow: headline xl, summary lg. Past 44rem: headline 2xl, summary xl — the tokens never change, the ladder does.
hl(2xl) md:scl(lg)

Base token, responsive ladder

Below 25rem the headline is the fixed 2xl clamp; at md the master step shifts the ladder +1 and the same hl(2xl) renders 3xl.

7 · Static scale — scl(fix)

scl(fix) re-points every stop from its fluid cqi clamp to the global static scale (--font-size-*): type changes only at the md:/lg: container breakpoints, never in between. Resize the cards — the first holds its exact sizes within each breakpoint tier and snaps at lg; the second (scl(fluid) opt-out inside a fixed wrapper) scales continuously.

scl(fix) hl(lg) lg:hl(xl)

Exactly 1.875rem, then exactly 3rem

The designer's spec: two precise sizes from the global --font-size-* scale, switched at the 44rem container breakpoint — no in-between scaling.
scl(fluid) — opt-out inside the fixed wrapper

Back on the fluid clamp

The wrapper sets scl(fix); this card's own scl(fluid) wins (nearest mode), so the headline tracks the card width continuously again.

Font families — fnt()

fnt(body | head | serif | mono | form) sets the font of the whole text column (maps to the global --font-* tokens). Headings follow the container font unless hl(<font>) overrides just the headline — so fnt(serif) makes everything serif, while hl(serif) gives you a serif headline over a sans body (the classic editorial split). Escape hatch: set --ui-content-font / --ui-content-heading-font directly.

Heading-font split — hl(<font>)

An editorial split: a serif headline over a sans body. hl(serif) writes only --ui-content-heading-font, so the body keeps the container font.

hl(serif) — serif headline, sans body

A serif headline sets the editorial tone

The body copy stays in the default sans --font-body for readability, while only the headline switches to --font-serif. Reverse it — a sans headline over a serif body — with fnt(serif) hl(body).
