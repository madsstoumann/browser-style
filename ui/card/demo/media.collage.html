UI: Media — Collage

A product card whose <ui-media> holds a collage instead of a single image: a nested <lay-out lg="grid(3c)"> with one nested <ui-media> frame per shot (a nested frame is always a plain frame — never a scroller, never absolutely-positioned into the outer box). With flush gaps (cg(0) rg(0)) and square frames the pattern tiles exactly: one asr(1/1) at 2fr equals two stacked asr(1/1) at 1fr. Each frame carries hov(zoom) for a per-tile hover zoom. Chip and sticker ride the outer frame's furniture grid: chip defaults to top-start, sticker to top-end. Price and buy-button are the stock price / actions content parts. No custom CSS on this page.

The collage is viewport-driven (lay-out breakpoints): grid(3c) from 720px, a columns(3) strip from 540–719px, stacked below. See the other <ui-media> demo pages — and the lightbox page for opening a collage fullscreen via a <ui-lightbox> popover toggle.

The pattern

This first card uses the word-size spacing tokens — xs="cg(sm) rg(sm) p(sm)" — for 8px gutters and a matching frame inset. With visible gutters the tiles carry no asr(): the large tile spans two rows plus the row-gap between them, which a fixed-ratio image can never fill — an aspect-less frame instead stretches to fill its grid area exactly (the frame's built-in minimum gives rows their height), so bottoms stay flush at any gap size. The flush-gap cards further down use cg(0) rg(0) + asr(1/1), where square tiling is exact.

Even three-up

The same pattern with an even collage: md="columns(3)" gives three equal tiles instead of grid(3c)'s one-large-plus-two-stacked. It suits a set of shots that carry equal weight — a lookbook row rather than a hero plus details. The source images are 2:3 portraits, so asr(2/3) tiles them at their native ratio and nothing is cropped. columns(3) is generated from md up — this build's config ships only columns(2) at sm — so the strip stacks below 540px.
