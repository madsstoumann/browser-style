UI: Card — Hero promo tile

An approximation of a familiar tablet-maker's promo tile — unaffiliated; original placeholder copy, a repo image, system fonts. The text column sits above the frame by plain DOM order inside variant="col" (no col-r needed), the surface is a gradient on --ui-card-bg, and the product is a transparent PNG in an obf(contain) frame with its default plate zeroed via --ui-media-bg. The buttons follow the reference's order (filled first); the system's own convention puts the accent CTA last (docs/content.md § actions).

See also: content.html (the text column) · media.html (the frame).

Content above media — col + DOM order

Nothing in variant="col" sets order: the two areas auto-place in the grid, so writing <ui-content> before <ui-media> is enough (and keeps reading order = visual order). Two knobs are custom properties rather than tokens — --ui-card-bg takes any background value, and --ui-media-bg: #0000 removes the frame's default 25 % plate that would otherwise box a transparent image. theme="light" pins the tile's colour scheme so the dark product never lands on a dark plate. The outline pill needs data-variant="outline" for its ring; the --outline class alone paints no border.
