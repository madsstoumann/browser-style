UI: Card — Media furniture

Overlay elements inside <ui-media>: <ui-beacon>, <ui-chip>, <ui-play>, <ui-save>, <ui-sticker>. All configured from the parent media= token as <el>(<value>) — position on the 9-code grid (ts tc te · cs cc ce · bs bc be), plus hue, size and corner.

Beacon — <ui-beacon>

The chip's live counterpart. Face with beacon(dts|pll|sld|tck), animation with beacon(bln|pls|brt|non), plus the usual <pos> / <hue> / <size>. Over imagery prefer pll/sld — the bare dot has no contrast plate.

Chip — <ui-chip>

A small pill label. Position with chip(<pos>), colour with chip(<hue>), size with chip(sm|lg|xl|2xl). The light/outline variants are addressable too: chip(lgt) (tinted surface) and chip(out) (bordered).

Marquee — <ui-marquee>

A full-width scrolling band across <ui-media>, driven entirely from the parent media= token — nothing on the <ui-marquee> itself. Position marquee(top) (default) / marquee(bot); hue marquee(<red…white>); size marquee(sm|lg|xl|2xl); plus modes marquee(loop) / marquee(seam) and marquee(fade). Sits at z-index:1, below the other furniture (chip/beacon/sticker are z-index:2). Content here is zero-markup: aria-label on an empty <ui-marquee> fills ::before/::after and doubles as the accessible name. Weight defaults to the component's — override with --ui-marquee-font-weight.

Full component: ui/marquee.

Play — <ui-play>

An interactive play button, default centred (cc); the glyph is a <ui-icon type="play-pause"> (morphs play↔pause). variant="reveal" hides it until the media is hovered/focused; theme= and size= apply. Card-only (interactive — never inside a reveal <summary>). Load @browser.style/play for the is-playing toggle, or point its <button> at a [popover] for a no-JS lightbox.

Save — <ui-save>

A save / favorite toggle, over the image (Amazon / IMDb style). The media= token carries position (save(<pos>), 9-code grid), colour (save(<hue>) — the 8 theme hues, aligned with chip/sticker) and size (save(sm|lg|xl); md is the default). The circle backdrop is on by default; hide it with save(non). The glyph is a <ui-icon type="shape" shape="heart|bookmark|star" variant="outline"> inside an invoker <button command="--save" commandfor="<card id>">; saved state = the button's aria-pressed. Bookmark defaults to the accent colour.

Sticker — <ui-sticker>

A disc, or a starburst with variant="sh:burst" (good for discounts). Position + hue via sticker(<pos>) / sticker(<hue>). A card can address one chip and one sticker together.
