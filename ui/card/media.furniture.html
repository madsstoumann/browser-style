UI: Card — Media furniture

Overlay elements placed inside <ui-media>: <ui-chip>, <ui-sticker>, <ui-save> and <ui-play>. Position and sub-theme come from the parent media= token — chip(<pos>) / sticker(<pos>) / save(<pos>) / play(<pos>) using the 9-code grid (ts tc te · cs cc ce · bs bc be), and chip(<hue>) / sticker(<hue>) for the palette (red orange green blue accent dark light subtle).

See also: media.html (the full <ui-media> reference).

Sticker — <ui-sticker>

A disc, or a starburst with variant="burst" (good for discounts). Position + hue via sticker(<pos>) / sticker(<hue>). A card can address one chip and one sticker together.

Play — <ui-play>

An interactive play button, default centred (cc); the glyph is a <ui-icon type="play-pause"> (morphs play↔pause). variant="reveal" hides it until the media is hovered/focused; theme= and size= apply. Card-only (interactive — never inside a reveal <summary>). Load @browser.style/play for the is-playing toggle, or point its <button> at a [popover] for a no-JS lightbox.
