UI: Card — Media shp() shapes

Clip a <ui-media> image (or video/iframe) to a shape via clip-path. Names are kept short: direction suffixes are -l/-r (left/right), -d/-u (down/up). The full set (32), from the opt-in media.shapes.css sheet. Every shape carries a matching-vertex morph target (--ui-shape-morph); add hov(shape) (all the tiles below) to animate it back to a full frame on hover — the base clip is static without it. The clip mechanism ships in media.css, the hover morph in media.hover.css, so both work with your own --ui-media-shape / --ui-shape-morph too.

See also: media.html (the full <ui-media> reference).

Forward — shp(x) hov(shape)

Rest = the shape; hover morphs it back to the full frame.

pt-d pt-u pt-l pt-r cut-l cut-r skew-l skew-r para rhomb inset hex arr-l arr-r chev-l chev-r star plus minus close msg frame frame-in bolt blinds-h blinds-v curve-d curve-u curve-l curve-r circle circ-45

Reversed — shp(x) hov(shape-rev)

hov(shape-rev) swaps base and target: rest = the full frame (square), hover morphs into the shape. Same set, reversed direction.
