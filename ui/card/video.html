Video play/pause — <ui-play> over <video>

Drop a <ui-play> onto a native <video> (no controls) and index.js wires it: the button toggles play/pause and mirrors the real playback state (glyph morphs play↔pause). The button fades out while playing, reappears on hover, and stays put when paused. To defer the download use native preload="none" with a poster (<video> does not support loading="lazy" — that's <img>/<iframe> only); the file is only fetched on first play. variant="reveal" hides the button until hover/focus.

YouTube — provider="youtube"

Same facade as the Vimeo embeds — data-preview is provider-agnostic: here a static <img data-preview> poster (Vimeo uses an animated <video data-preview> loop) sits over a lazy <iframe>, lifted by z-index so source order doesn't matter. The <ui-play> click drops the poster, appends autoplay=1 and hands off to the YouTube player. (An iframe isn't an HTMLMediaElement, so it uses the click facade, not command="play-pause" — that's native <video> only.)
