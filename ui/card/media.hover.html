UI: Card — Media hov() effects

Hover a card. The transform family moves the image inside a fixed frame (zoom / pan / rot-r / rot-l / fixed 3D tilt-out / tilt-in, plus cursor-driven track / drift / tilt); the filter family transitions CSS filters (gray / blur / bright / dim / sat); and shape morphs a shp() clip. All animated props share one transition list, so effects compose (e.g. hov(shape) hov(zoom)). Tune with --ui-media-hv-* / --ui-media-hover-duration; all respect prefers-reduced-motion. Effects live in media.hover.css. The three cursor-driven effects (track / drift / tilt) need a tiny pointer handler and are shown last.

See also: media.html (the full <ui-media> reference).

transform · CSS

hov(zoom)

The image scales up inside the frame.

 transform · CSS

hov(pan)

Zooms and drifts in a fixed direction.

 transform · CSS

hov(rot-r)

A subtle clockwise spin (rotate: longhand, composes with flp()).

 transform · CSS

hov(rot-l)

The counter-clockwise mirror of rot-r.

 transform · CSS

hov(tilt-out)

Scales slightly and tilts the top toward you (fixed 3D, no JS). Tune --ui-media-hv-tilt-fixed.

 transform · CSS

hov(tilt-in)

Scales slightly and tilts the top away (inward). The mirror of tilt-out.

 clip · CSS

hov(shape)

Morphs a shp() clip to its full-frame target (see media.shape.html).

 filter · CSS

hov(gray)

Rest grayscale, hover restores colour.

 filter · CSS

hov(blur)

Rest blurred, hover sharpens. Tune --ui-media-hv-blur.

 filter · CSS

hov(bright)

Rest dimmed, hover restores full brightness. Tune --ui-media-hv-bright-rest.

 filter · CSS

hov(dim)

Darkens on hover (pairs with overlaid text). Tune --ui-media-hv-dim.

 filter · composes

hov(gray) hov(blur)

Filters stack — one shared filter declaration built from per-effect vars.

Cursor-driven — needs JS

The only effects that need JavaScript: hover.js sets --ui-media-mx / --ui-media-my (−1..1) on the frame from a pointermove handler; the CSS reads them.

transform · JS

hov(track)

hov(drift)

hov(tilt)
