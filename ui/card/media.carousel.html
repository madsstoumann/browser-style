UI: Media — Carousel

CSS-only <ui-media> carousel: a scroll-snap row with native ::scroll-marker dots + ::scroll-button() arrows, driven by a media= token string. Native in Chromium; elsewhere /polyfill/carousel.js (JS off → plain swipe scroller).

Reveal on hover — arw(rev)

arw(rev) hides the arrows until the media is hovered or keyboard-focused (touch keeps them visible). Dots stay always-visible in a band below.

Bar — mrk(bar)

A thin scrollbar: one hairline track, the current slide's stretch drawn thicker (the thumb). Click-to-jump, keyboard-navigable. The size scale sets the bar's width; overlay by default, or in a band with mrk(blw).

Thumbnails — mrk(tmb)

mrk(tmb) turns dots into thumbnails — each slide sets --ui-carousel-thumb-url. Corner via mrk(ts/te/bs/be), size via mrk(). (JS autoplay + video version below.)

Default 4/3. tmb(1/1) · tmb(3/4) · tmb(16/9) · tmb(3/2) · tmb(2/3) reshape them (slash, not colon).

Cards as pages — overflow media="pages"

Each <ui-reveal> card snaps as a page; stagger="rise" reveals it on the way in. Use block effects (rise/fall/fde/zom/blr) — inline slides break scroll-to-end.

JS-enhanced

These need carousel.js — autoplay, seamless loop, video and a play/pause handle. All degrade to a plain scroller with JS off.

Autoplay & loop — auto() · loop

auto() advances on a timer (pausing on hover/focus); loop clones the end slides so wrapping is seamless.

auto(3s) loop mrk(pll)

Autoplay + pill timer

Advances every 3s, seamlessly wraps; pauses on hover/focus.

 loop

Seamless loop

Next past the last smooth-scrolls into a cloned slide, then invisibly resets — no jump.

Drop the arrows (nav(mrk)) or all navigation (nav(non)) — the <ui-play> control stays the handle.

nav(mrk) mrk(pll) auto(3s) loop play(bs)

Pills only — no arrows

Arrows dropped; the pill timers and play/pause control remain.

No navigation — play only

No dots, no arrows; the play/pause button is the sole control.
