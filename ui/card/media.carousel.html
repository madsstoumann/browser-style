UI: Media — Carousel

CSS-only <ui-media> carousel: a scroll-snap row with native ::scroll-marker dots + ::scroll-button() arrows, driven by a media= token string. Native in Chromium; elsewhere /polyfill/carousel.js (JS off → plain swipe scroller).

Stagger — layered & multi-card slides

Multiple cards per page, revealed with stagger. Two ways to build it: a flat <lay-out overflow pages> (scroll-driven, per-card) or a <ui-media> carousel of grouped slides (snap-triggered, two-channel).

<lay-out overflow pages stagger> — flat cards, no ui-media

Flat <ui-reveal> cards in one <lay-out>; pages snaps per page of N (responsive 2→3), stagger="rise" reveals each card as it swipes in (scroll-driven, re-runs). Controls via the shared nav="blw" arrow="bare". No inner slide wrappers — compare the crd()+ani() ui-media version below. Note: use a block-axis (rise/fall) or no-translate (fde/zom/blr) effect here — an inline slide (lft/rgt) translates cards along the scroll axis, breaking scroll-to-end and overlapping neighbours' controls.

13 · Full-screen carousel — bleed + overflow="preview-2xl center"

A cinematic hero carousel. The peek is a <lay-out overflow> feature (not <ui-media>): center centers the current slide and reveals a sliver of the previous and next slides; preview-2xl sizes each peek to 25% of the carousel width, so the current slide is ≈50% and each neighbour ≈25%. bleed takes it edge-to-edge; controls compose unchanged — nav="dot" shows dots only (no arrows), dot="hyb blw" drops a hybrid dot/pill row into a band below. gaps adds a gutter (matching the inter-item gap) before the first and after the last item, so the ends aren't flush.

14 · Full-screen carousel, seamless loop + autoplay — loop · auto()

Same cinematic carousel with loop + auto="4s" — progressive enhancement from the shared carousel script (@browser.style/card index.js, the same engine that loops <ui-media>); with JS off it stays a finite scroller. It clones the last slide before the first and the first after the last, so the real previous/next slides fill the side peeks, the current slide stays centered even at the ends, and autoplay advances forward forever — rolling into a clone, then hopping instantly to its real twin (identical frame → invisible). The hybrid dot fills as a progress timer; autoplay pauses on hover/focus. Clone dots are auto-suppressed, so the dot count still matches the real slides.
