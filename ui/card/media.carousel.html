UI: Media — Carousel

The CSS-only <ui-media> carousel — a flex scroll-snap row with native ::scroll-marker dots and ::scroll-button() arrows, no JavaScript. Driven by the media= token string: nav() controls, arw() glyph/placement/size/bare, dot() pills, and nav(blw) control bands. Native in Chromium; elsewhere /polyfill/carousel.js (conditionally loaded) provides the same controls — with JS off it degrades to a plain swipe scroller.

See also: media.html (the <ui-media> frame) · index.html (the full engine) · content.html (the <ui-content> side) · media.md (token reference).

Carousel — media="nav"

Add the nav token to put multiple sources in a scroll-snap row. By default it shows CSS-only navigation — dots (::scroll-marker) and prev/next arrows (::scroll-button()) — with no extra markup and no JS. Native in Chromium; elsewhere the carousel polyfill supplies the same controls (JS off → plain swipe scroller).

Carousel controls — nav()

Pick which controls show by folding them into the token: bare nav (both), nav(dot), nav(arw), or nav(non). nav(non) leaves a bare swipe scroller — there is no separate gallery variant; a carousel with its controls off is the gallery.

Carousel theming

Dots and arrows are token-driven. Recolour dots with --ui-media-dot-*. Each arrow is a circular button — colour the circle with --ui-media-arrow-bg (default a frosted semi-transparent white, Instagram-style, with a soft --ui-media-arrow-shadow) and size it with --ui-media-arrow-size. The chevron is dark by default (for the light circle); for a dark or accent circle switch the glyph to white with arw(lgt). Square off the circle with --ui-media-arrow-radius.

Carousel arrows — arw()

Switch the arrow glyph with arw(arr) (full arrow, shaft + head) — default is arw(chv). Place the edge arrows vertically with arw(top) / arw(bot) (default arw(mid)). Group both into an adjacent pair with arw(set) (pair it with arw(bot) for a bottom-end set).

Carousel bare arrows — arw(bare)

arw(bare) drops the circle and renders the glyph itself as a coloured arrow — set the colour with --ui-media-arrow-color (default white over an image; auto-flips dark under nav(blw)). Bare drops the circle and its --ui-media-arrow-shadow, so a white glyph relies on a dark image — over bright photos keep the frosted circle or move controls to a nav(blw) band. Composes with arw(arr) and every placement atom.

Carousel pills — dot(pll)

Swap the round dots for pills with dot(pll). The active pill fills left→right over --ui-media-autoplay (default 5s) as a timer hint — it restarts whenever the active slide changes. JS-driven autoplay (which advances the slide on that cadence) lands later; the indicator is wired now. Under reduced-motion the active pill simply shows filled. Recolour with --ui-media-pill-track / --ui-media-pill-fill.

Navigation below the media — nav(blw)

nav(blw) moves both controls off the image into a reserved bottom band (dots centered, arrows at the ends) — the media keeps its full frame above. Size the band with --ui-media-band (default 2.75rem) and colour it with --ui-media-controls-bg. Combine with arw(set) to pin the dots to the start and pair the arrows at the end, or dot(pll) for a timer bar. (Arrow placement atoms arw(top/bot) are for the overlay variant; nav(blw) owns its own vertical placement.)

Navigation above the media — nav(abv)

nav(abv) is the mirror of nav(blw) — controls sit in a reserved band above the media instead of below. Here the carousel is a bare <ui-media> (no radius/clip) with rounded <ui-card> slides as children. Pair with arw(set) for a prev/next cluster top-right; the second drops the dots (dot(non)) and uses full-arrow glyphs (arw(arr)).

Dot position in the band — dot(sta) · dot(ctr) · dot(end)

Vertical carousel — axis(y)

axis(y) turns the carousel vertical — a column scroll-snap row, snapping on the Y axis. The same nav() controls apply: dots become a vertical column on the inline-end edge, the arrows become up/down (the single base glyph, rotated) at top & bottom of that edge. arw(sta) moves them to the other edge; arw(set) stacks the pair at the bottom; arw(bare) and the sizes all compose. Give the frame a portrait asr() so there's height to scroll.

Plain scrollbar — nav(bar)

nav(bar) drops the dots/arrows and shows the native thin scrollbar as the only affordance — works on either axis, and looks platform-correct out of the box (scrollbar-color: auto). Override colours with a single --ui-media-scrollbar-color token ("<thumb> <track>", e.g. #ccc transparent) and width with --ui-media-scrollbar-width (thin default).

Multiple items per slide — group wrappers

Wrap multiple items in a group element — the carousel snaps the whole group as one slide (one dot). Inner layout is yours (here the .slide-cols class).

Same carousel, groups are plain <div>s, and three pieces of overlay furniture — <ui-chip>, <ui-sticker>, <ui-play> — sit over the frame. None become slides; the dot count stays at one per group.

JS-enhanced behaviors

Two things CSS can't do are layered on by ui-media.js — strictly progressive enhancement. With JS off the carousels still scroll, snap, show dots/arrows; these tokens just no-op. The script runs one querySelectorAll for the JS tokens (auto, loop) — plain <ui-media> are never touched.

auto(3s) loop dot(pll)

Autoplay + pill timer

Advances every 3s, seamlessly wraps; pauses on hover/focus. Pill fills in sync.

 loop

Seamless loop

Next past the last smooth-scrolls into a cloned slide, then invisibly resets — no jump. Works with dots + arrows, both directions.

Both compose with axis(y) — the seamless loop and autoplay work on the vertical axis too (clones prepend/append, scrollend hops on scrollTop).

Play/pause control — <ui-play>

Drop a <ui-play> into an autoplay carousel and ui-media.js wires it to the timer. Because a scroll container's furniture scrolls away with the slides, the control is pinned to the scrollport with position:sticky — place it with the same corner tokens as other furniture (play(bs) bottom-left default, play(be) bottom-right, etc.). When a control is present it becomes the sole pause mechanism (no hover/focus auto-pause), so the play/pause glyph always matches reality; it also freezes the pill/thumb fill timer via --ui-media-play-state. The button toggles aria-pressed and emits a ui-play-toggle event. Add variant="reveal" to hide it until the frame is hovered or focused.

Always visible; click to pause — the pill timer freezes with it.

Carousel of videos — pause on slide change

A nav carousel whose slides are nested <ui-media> frames each holding a native <video> + <ui-play>. index.js only wires the pause-on-leave behaviour when the carousel contains a video — an IntersectionObserver pauses a slide's video as it scrolls out, so you never hear two at once. Each per-slide <ui-play> toggles its own video (and fades while playing); a page-wide solo listener also pauses any other playing video when you start a new one.

Two ways to write it — media= tokens or nav/arrow/dot attributes

Same options, two entry points. Left: the inheritable media= string (parens + prefix; can be set on the <ui-card> / CMS and inherits down). Right: dedicated grouped attributes on the <ui-media> itself (whole-word, no repetition; not inherited). Both render identically. Ink names are shared across scrim, arrows and dots: lgt · drk · sub (and med for scrim).

Bare <ui-media> — no <ui-card>

Every configuration works on a standalone <ui-media media="…"> too — the media= tokens drive it directly, no <ui-card> or <cq-box> needed. Two complex setups below. (If you need border-radius/overflow, put it on a wrapper — never on ui-media itself, that beats the component's :where() rules and breaks the scroller.)

Thumbnail navigation — dot(tmb)

Turn the ::scroll-marker-group dots into image thumbnails with dot(tmb). Each slide is its own layered <ui-card> (unique headline + CTA), full-bleed (4/3) with content overlaid bottom-left (ovr(bl) + scm). Each slide sets its thumbnail via style="--ui-media-thumb-url: url(…)" (custom property — swaps to typed attr() once Baseline). Place the rail in any corner with dot(tl) / dot(tr) / dot(bl) / dot(br) — here top-right. The last two slides are videos: one silent autoplay muted loop background (preload="auto", since it plays immediately) and one manual with a <ui-play> (preload="metadata" — loads dimensions + the first frame for a snappy start without buffering the whole file; use preload="none" to defer entirely behind the poster). The manual video pauses when you swipe past its slide.

Staggered content reveal — stagger · ani()

Pure CSS, no JavaScript. Each slide is a container-type: scroll-state query container; when it becomes the snapped (current) slide, a @container scroll-state(snapped: inline) query reveals its <ui-content> children with a per-child transition-delay. It's a time-based transition (not scroll-driven), so the ~1s cascade plays identically on arrow-click, swipe or autoplay — the technique behind chrome.dev's hero slider. Pick the reveal type with ani() — rise (default) · fall · lft · rgt · zom · blr · fde. Tune with the shared --stagger-* tokens.

Layered cards + stagger — two channels (crd() + ani())

The layered cards pattern (3 cards per <ui-slide>) with two independent reveal channels: crd(rise) makes the cards rise + cascade in as units, while each card's own ani() controls how its content enters — here card 1 slides in (ani(lft)), card 2 zooms (ani(zom)), card 3 fades (ani(fde)). Both cascade (card index, then child index). Pure CSS.
