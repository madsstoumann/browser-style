UI: Card — Media

Everything that controls the media frame: the asr() aspect-ratio, flp() flip, obf() object-fit, obp() object-position, rds() radius — and scm scrim. All driven by the media= token string.

Aspect-ratio — asr()

Sets the media frame's aspect-ratio (and drops its min-block-size so the ratio wins).

Without an asr(), the frame falls back to its natural image height (bounded by --ui-media-min, default 12.5rem).

asr(1/1) asr(6/7) asr(3/4) asr(2/3) asr(4/3) asr(3/2) asr(16/9) asr(21/9)

Radius — rds()

Inside <ui-card>/<ui-reveal> the parent rounds and clips the frame, so you don't set corners on the media. Standalone <ui-media> can round its own corners with rds() — the same scale as the card's variant="rds(…)": sm md lg xl 2xl full pill, plus -sq squircle variants (sm-sq md-sq lg-sq xl-sq) that add a superellipse corner-shape.

rds(none) rds(sm) rds(md) rds(lg) rds(xl) rds(2xl) rds(pill) rds(full) rds(sm-sq) rds(md-sq) rds(lg-sq) rds(xl-sq)

Object-position — obp()

When the frame's ratio crops the image, obp() picks which part stays in view — the same 9-code grid used everywhere else: tl tc tr · cl cc cr · bl bc br. All nine below share one square frame and one wide image.

obp(tl) obp(tc) obp(tr) obp(cl) default obp(cr) obp(bl) obp(bc) obp(br)

Object-fit — obf()

The frame defaults to object-fit: cover (fill & crop). Override per instance with the obf() token (or the --ui-media-fit custom property): contain (fit whole image), fill (stretch), none (intrinsic size, cropped).

cover (default) contain fill none

Flip — flp()

Mirror the media without editing the asset. flp(h) flips horizontally, flp(v) vertically, flp(hv) both. It uses transform on the image, separate from the scale/translate that hov() drives, so flip and hover compose.

original flp(h) flp(v) flp(hv)

Scrim — scm over media

A scrim is the darkening gradient painted over the image (via ui-media::after) so overlaid text stays legible. It has three composable axes: direction (scm(pos) — the 3×3 grid below), size (scm(sm md lg xl)), and intensity (scm(sheer lgt med drk solid)). The nine cards show every scm(pos) with an ovr() eyebrow + headline over the scrim; the dropdowns apply a size, intensity, and colour to all of them at once (colour defaults to the standard dark — switch to hotpink to see the gradient shape clearly).
