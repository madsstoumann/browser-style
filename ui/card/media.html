UI: Card — <ui-media>

Everything that controls the media frame: the asr() aspect-ratios, obp() object-position, flp() flip, hov() hover effects, the scm scrim, and <ui-chip>/<ui-sticker> overlays. All driven by the media= token string — no JavaScript (the one exception, cursor-tracked hov(track), is noted inline). The CSS-only nav carousel lives in carousel.html; all <video> / provider= examples live in video.html.

See also: carousel.html (the carousel) · index.html (the full engine) · content.html (the <ui-content> side) · ui-card-tokens.md (token reference).

Aspect-ratio — asr()

Sets the media frame's aspect-ratio (and drops its min-block-size so the ratio wins).

Without an asr(), the frame falls back to its natural image height (bounded by --ui-media-min, default 12.5rem).

asr(1/1) asr(6/7) asr(3/4) asr(2/3) asr(4/3) asr(3/2) asr(16/9) asr(21/9)

Radius — rds()

Inside <ui-card>/<ui-reveal> the parent rounds and clips the frame, so you don't set corners on the media. Standalone <ui-media> can round its own corners with rds() — the same scale as the card's variant="rds(…)": sm md lg xl 2xl full pill, plus -sq squircle variants (sm-sq md-sq lg-sq xl-sq) that add a superellipse corner-shape.

rds(none) rds(sm) rds(md) rds(lg) rds(xl) rds(2xl) rds(pill) rds(full) rds(sm-sq) rds(md-sq) rds(lg-sq) rds(xl-sq)

Object-position — obp()

When the frame's ratio crops the image, obp() picks which part stays in view — the same 9-code grid used everywhere else: tl tc tr · cl cc cr · bl bc br. All nine below share one square frame and one wide image.

obp(tl) obp(tc) obp(tr) obp(cl) obp(cc) obp(cr) obp(bl) obp(bc) obp(br)

Object-fit — obf() / --ui-media-fit

The frame defaults to object-fit: cover (fill & crop). Override per instance with the obf() token (or the --ui-media-fit custom property).

cover (default) contain fill

Shapes — shp()

Adds a clip-path to images, videos and iframes within <ui-media>. Names are kept short: direction suffixes are -l/-r (left/right), -d/-u (down/up). The full set (31), from the opt-in media.shapes.css sheet. Every shape carries a matching-vertex morph target (--ui-shape-morph) — hover any of them and it animates back to a full frame (the groundwork for a scroll-driven reveal). The clip + hover-morph mechanism itself lives in media.css, so it also works with your own --ui-media-shape / --ui-shape-morph. Morph is on by default for now; a token to gate it comes later.

pt-d pt-u cut-r cut-l skew-r skew-l para rhomb inset pt-l pt-r hex plus minus blinds-h blinds-v frame chev-l chev-r star arr-l arr-r close bolt msg curve-d curve-u curve-r curve-l circle circ-45

Flip — flp()

Mirror the media without editing the asset. flp(h) flips horizontally, flp(v) vertically, flp(hv) both. It uses transform on the image, separate from the scale/translate that hov() drives, so flip and hover compose.

original flp(h) flp(v) flp(hv)

Hover effects — hov()

Hover (or focus) a card. zoom / pan / track / drift move the image inside a fixed frame. Tune with --ui-media-hv-* and --ui-media-hover-duration. All respect prefers-reduced-motion.

image

hov(zoom)

The image scales up inside the frame.

 image

hov(pan)

Zooms and drifts in a fixed direction.

 image · needs JS

hov(track)

The image follows the cursor — the only effect that needs a tiny pointer handler (below).

 image · needs JS

hov(drift)

Oversized image shrinks slightly and drifts opposite the cursor. Same pointer handler as track.

Scrim — scm over media

A scrim is the darkening gradient painted over the image (via ui-media::after) so overlaid text stays legible. ovr(pos) places the content over the media; bare scm auto-matches that position, or pass an explicit scm(pos). The colour is the --ui-media-scrim-color token.

ovr(tl) scm — topTop scrim ovr(bl) scm — auto-matchBottom scrim scm(cc) + custom colourCentre band

Intensity — a second scm() token sets how dark the scrim is: scm(lgt), scm(med) (default), scm(drk). Combine with a position, e.g. scm scm(drk).

scm(lgt)Light scm(med)Medium scm(drk)Dark

Furniture — chip, play, save & sticker

Place <ui-chip> (a pill label) or <ui-sticker> (a disc, or a starburst with variant="burst") inside <ui-media>. Position and sub-theme come from the parent media= token: chip(<pos>) / sticker(<pos>) with the 9-code grid (ts tc te · cs cc ce · bs bc be), and chip(<hue>) / sticker(<hue>) for the palette (red orange green blue accent dark light subtle). A card can address one chip and one sticker.
