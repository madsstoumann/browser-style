UI: Card — <ui-media>

Everything that controls the media frame: the asr() aspect-ratios, obp() object-position, flp() flip, hov() hover effects, the scm scrim, <ui-chip>/<ui-sticker> overlays, <video> and the CSS-only nav carousel. All driven by the media= token string — no JavaScript (the one exception, cursor-tracked hov(track), is noted inline).

See also: index.html (the full engine) · content.html (the <ui-content> side) · ui-card-tokens.md (token reference).

Aspect-ratio — asr()

Sets the media frame's aspect-ratio (and drops its min-block-size so the ratio wins). Eight stops cover the common print/screen ratios. Same image, same width — only the crop changes. These are standalone <ui-media> — no <ui-card> wrapper — with media= on the element itself (overlay furniture works the same).

asr(1/1) asr(6/7) asr(3/4) asr(2/3) asr(4/3) asr(3/2) asr(16/9) asr(21/9)

Without an asr(), the frame falls back to its natural image height (bounded by --ui-media-min, default 12.5rem).

Object-position — obp()

When the frame's ratio crops the image, obp() picks which part stays in view — the same 9-code grid used everywhere else: tl tc tr · cl cc cr · bl bc br. All nine below share one square frame and one wide image.

obp(tl) obp(tc) obp(tr) obp(cl) obp(cc) obp(cr) obp(bl) obp(bc) obp(br)

Object-fit — obf() / --ui-media-fit

The frame defaults to object-fit: cover (fill & crop). Override per instance with the obf() token (or the --ui-media-fit custom property) for contain (letterbox, whole image visible) — handy for logos and product shots that must not crop.

cover (default) contain fill

Flip — flp()

Mirror the media without editing the asset. flp(h) flips horizontally, flp(v) vertically, flp(hv) both. It uses transform on the image, separate from the scale/translate that hov() drives, so flip and hover compose.

original flp(h) flp(v) flp(hv)

Hover effects — hov()

Hover (or focus) a card. zoom / pan / track move the image inside a fixed frame. Tune with --ui-media-hv-* and --ui-media-hover-duration. All respect prefers-reduced-motion.

Scrim — scm over media

A scrim is the darkening gradient painted over the image (via ui-media::after) so overlaid text stays legible. ovr(pos) places the content over the media; bare scm auto-matches that position, or pass an explicit scm(pos). The colour is the --ui-media-scrim-color token.

ovr(tl) scm — topTop scrim ovr(bl) scm — auto-matchBottom scrim scm(cc) + custom colourCentre band

Intensity — a second scm() token sets how dark the scrim is: scm(lgt), scm(med) (default), scm(drk). Combine with a position, e.g. scm scm(drk).

scm(lgt)Light scm(med)Medium scm(drk)Dark

Media overlays — chip & sticker

Place <ui-chip> (a pill label) or <ui-sticker> (a disc, or a starburst with variant="burst") inside <ui-media>. Position and sub-theme come from the parent media= token: chip(<pos>) / sticker(<pos>) with the 9-code grid (ts tc te · cs cc ce · bs bc be), and chip(<hue>) / sticker(<hue>) for the palette (red orange green blue accent dark light subtle). A card can address one chip and one sticker.

Play affordance — <ui-play>

An interactive play button, default centered (cc); the glyph is a <ui-icon type="play">. variant="reveal" hides it until the media is hovered/focused; theme= and size= apply. Card-only (interactive — never inside a reveal <summary>). Load @browser.style/play for the is-playing toggle, or point its <button> at a [popover] for a no-JS lightbox.

Video

Carousel — media="nav"

Add the nav token to put multiple sources in a scroll-snap row. By default it shows CSS-only navigation — dots (::scroll-marker) and prev/next arrows (::scroll-button()) — with no extra markup and no JS. Chromium-only for now; elsewhere it degrades to a plain swipe scroller.

Carousel controls — nav()

Pick which controls show by folding them into the token: bare nav (both), nav(dots), nav(arrows), or nav(none). nav(none) leaves a bare swipe scroller — there is no separate gallery variant; a carousel with its controls off is the gallery.

Carousel theming

Dots and arrows are token-driven. Recolour dots with --ui-media-dot-*. Each arrow is a circular button — colour the circle with --ui-media-arrow-bg (default semi-transparent black) and size it with --ui-media-arrow-size. The chevron is white by default (for the dark circle); for a light circle switch to the built-in dark glyphs: --ui-media-arrow-prev/-next: var(--ui-media-arrow-prev-dark/-next-dark). Square off the circle with --ui-media-arrow-radius.
