UI: Media — Carousel

The CSS-only <ui-media> carousel — a flex scroll-snap row with native ::scroll-marker dots and ::scroll-button() arrows, no JavaScript. Driven by the media= token string. Native in Chromium; elsewhere /polyfill/carousel.js (conditionally loaded) provides the same controls — with JS off it degrades to a plain swipe scroller.

See also: media.html (the frame) · index.html (the engine) · content.html (the <ui-content> side) · media.carousel.md (token reference).

3 · Arrow glyph — arw()

The glyph is a chevron by default. arw(arr) swaps it for a full arrow (shaft + head). arw(bare) drops the circle and paints the glyph itself as a recolourable shape (--ui-media-arrow-color, default white over an image, auto-dark in a band).

5 · Overlay placement — arw(mid/top/bot) · arw(set)

On-media arrows sit vertically centered (arw(mid), default). arw(top) / arw(bot) move them to the edges; arw(set) groups both into an adjacent pair at the inline-end (pair it with arw(bot) for a bottom-end set).

6 · Control bands — nav(blw) / nav(abv)

nav(blw) / nav(abv) move both controls off the image into a reserved band below / above the media — the frame stays clean. Size it with --ui-media-band, colour it with --ui-media-controls-bg. Combine with arw(set) to pair the arrows at the end. Shown below in <ui-card>s, then the above mirror (nav(abv)) as standalone <ui-media> — a band above a card would read as stray whitespace at the card top.

10 · Dots & pills — dot() · dot(pll)

Recolour dots with --ui-media-dot-* and size them with dot(sm|md|lg|xl). dot(pll) swaps round dots for pills whose active fill runs left→right over --ui-media-autoplay (a timer hint); width via --ui-media-pill-width.

11 · Thumbnail navigation — dot(tmb)

Turn the dots into image thumbnails with dot(tmb). Each slide sets its thumbnail via style="--ui-media-thumb-url: url(…)". Place the rail in any corner with dot(tl/tr/bl/br) and size it with dot(sm|md|lg|xl). (CSS-only; a JS-enhanced version with autoplay + video lives in the JS section below.)

Plain images (no cards), 16/9, larger rail (dot(lg)) anchored bottom-right (dot(br)).

12 · Vertical carousel — axis(y)

axis(y) snaps on the Y axis: dots become a column on the inline-end edge, arrows become up/down. arw(sta) moves them to the other edge; arw(set) stacks the pair at the bottom (arw(set) arw(top) at the top); arw(bare) and the sizes compose. Control bands work on both edges — nav(blw) below, nav(abv) above.

Staggered content reveal — stagger · ani()

Pure CSS, no JavaScript. When a slide becomes the snapped one, a scroll-state(snapped) query reveals its <ui-content> children with a per-child transition-delay. Pick the reveal type with ani() — rise (default) · fall · lft · rgt · zom · blr · fde.

Play/pause control — <ui-play>

Drop a <ui-play> into an autoplay carousel and ui-media.js wires it to the timer. Pinned to the scrollport with position:sticky; place it with the corner tokens (play(bs) / play(be)). Add variant="reveal" to hide it until hover/focus.

Two ways to write it — media= tokens or nav/arrow/dot attributes
