UI: Card — <ui-media> (Rendered)

media.html recreated by the rendering engine: every frame and card on this page is built at runtime by render.js from UCF data files in data/demo/, combined with presets from card.presets.json and presets.demo.media.json. Sections that show the same content in different looks reuse one UCF file with swapped preset references — that is the point of presets. Chip/sticker positions and hues come from content fields; the renderer appends the matching media= tokens. All DOM via createElement/textContent — no innerHTML.

Everything that controls the media frame: the asr() aspect-ratios, obp() object-position, flp() flip, hov() hover effects, the scm scrim, and <ui-chip>/<ui-sticker> overlays. The CSS-only nav carousel lives in carousel.html; all <video> / provider= examples live in video.html.

Aspect-ratio — asr()

Sets the media frame's aspect-ratio (and drops its min-block-size so the ratio wins). Eight stops cover the common print/screen ratios. Same image, same width — only the crop changes. These are standalone <ui-media> — no <ui-card> wrapper — one UCF file (media-01) rendered through eight media-asr-* presets.

Without an asr(), the frame falls back to its natural image height (bounded by --ui-media-min, default 12.5rem).

Corners — rds()

Inside <ui-card>/<ui-reveal> the parent rounds and clips the frame, so you don't set corners on the media. Standalone <ui-media> can round its own corners with rds() — the same scale as the card's variant="rds(…)": sm md lg xl 2xl full pill, plus -sq squircle variants (sm-sq md-sq lg-sq xl-sq) that add a superellipse corner-shape. One UCF file (media-02), four media-rds-* presets.

Object-position — obp()

When the frame's ratio crops the image, obp() picks which part stays in view — the same 9-code grid used everywhere else: tl tc tr · cl cc cr · bl bc br. All nine below share one square frame and one wide image — one UCF file (media-03), nine media-obp-* presets.

Object-fit — obf() / --ui-media-fit

The frame defaults to object-fit: cover (fill & crop). Override per instance with the obf() token (or the --ui-media-fit custom property) for contain (letterbox, whole image visible) — handy for logos and product shots that must not crop. One UCF file (media-04); the contain preset carries the alt surface via preset styles.

Flip — flp()

Mirror the media without editing the asset. flp(h) flips horizontally, flp(v) vertically, flp(hv) both. It uses transform on the image, separate from the scale/translate that hov() drives, so flip and hover compose. Same UCF file as the corners section (media-02), four presets.

Hover effects — hov()

Hover (or focus) a card. zoom / pan / track / drift move the image inside a fixed frame. Tune with --ui-media-hv-* and --ui-media-hover-duration. All respect prefers-reduced-motion.

Scrim — scm over media

A scrim is the darkening gradient painted over the image (via ui-media::after) so overlaid text stays legible. ovr(pos) places the content over the media; bare scm auto-matches that position, or pass an explicit scm(pos). The colour is the --ui-media-scrim-color token — the third card overrides it via preset styles.

Size — a scm() token sets how far the gradient reaches across the frame: scm(sm) hugs the edge, scm(md) (default), scm(lg) reaches across. Combine with a position, e.g. scm(bc) scm(lg).

Intensity — a scm() token sets how dark the scrim is: scm(sheer), scm(lgt), scm(med) (default), scm(drk), scm(solid). Combine with a position, e.g. scm scm(drk).

Media overlays — chip & sticker

Place <ui-chip> (a pill label) or <ui-sticker> (a disc, or a starburst with variant="sh:burst") inside <ui-media>. Position and sub-theme come from the parent media= token: chip(<pos>) / sticker(<pos>) with the 9-code grid (ts tc te · cs cc ce · bs bc be), and chip(<hue>) / sticker(<hue>) for the palette (red orange green blue accent dark light subtle). A card can address one chip and one sticker. Here the chip/sticker text, position and hue are content (UCF chip/sticker fields) — the renderer appends the tokens; the look is the base showcase preset.

The full 9-position grid (ts tc te · cs cc ce · bs bc be), each a themed <ui-sticker variant="sh:burst"> starburst — good for discounts. Top row = corners + top-centre; middle row = the centre line (cs cc ce); bottom row = bottom edge.

Not expressible via UCF/render.js: Responsive images <ui-media> JS (the cdn="on" / quality= / breakpoints= srcset-upgrade showcase — those are per-media-element transport attributes the renderer does not model).
