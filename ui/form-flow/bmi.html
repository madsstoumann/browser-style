UI: Components > FormFlow > BMI calculator

The BMI calculator rebuilt as a form. Height and weight are sliders whose units come from ui.format. The rule set computes the BMI as weight ÷ (metres × metres), rounded to two places, and six named conditions, one per WHO category. The category is a text block with cases and show: "first"; the colours are page CSS on [data-case]. The rule set has no rules, and the form is a calculator: { "mode": "page", "submit": false }. Open it in the form editor.
