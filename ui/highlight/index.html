UI: Components

Highlight

Highlight is a CSS-only custom element that simulates a pen marker.
Set the marker color with fill (a preset name or any CSS color), an optional text color with ink, and a stroke style with variant.

You can highlight anything inline, even across several words that wrap onto the next line of running text without breaking.

Presets

The four classic markers: green, yellow, orange and pink.

Custom colors

Pass any CSS color to fill: #c9b8ff, oklch(), or a dark fill with light ink.

Variants

Beyond the full block, there is an underline marker and a strike-through.
