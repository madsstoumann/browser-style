UI: Tabs

<ui-tabs> is a CSS-only tabbed interface built on native <details> and <summary> elements. Use the name attribute on each <details> for exclusive open behavior. Structural behavior (shape, layout, animation) comes from the variant attribute. Decoration (indicator style, active-tab color, etc.) is driven entirely by CSS tokens — add your own classes that flip token values.
