UI: Tabs

<ui-tabs> is a CSS-only tabbed interface built on native <details> and <summary> elements. Use the name attribute on each <details> for exclusive open behavior, and compose the look with space-separated tokens on the variant attribute.

Default

Default indicator is an underline tracking the active tab via CSS anchor positioning.
