UI: Tabs

<ui-tabs> is a CSS-only tabbed interface built on native <details> and <summary> elements. Use the name attribute on each <details> for exclusive open behavior, and compose the look with space-separated tokens on the variant attribute plus optional standalone attributes (indicator, no-background, no-collapse).

Header bar

Tabs sit inside a tinted horizontal bar (the ::before header background). Shape comes from variant, the active indicator comes from indicator.
