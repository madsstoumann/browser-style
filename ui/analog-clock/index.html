UI: Analog Clock

CSS

<ui-analog-clock> is a CSS-first analog clock. Compose it from native elements: <ol> for numerals, <ul> for indices, <nav> for hands and date, <span> for the label. Numeral and index positions are computed from sibling-index() / sibling-count() — no inline angles needed.

This page demonstrates the CSS-only approach. Because a clock needs the current time to place its hands, a tiny JS helper at the bottom of this page sets the animation delays (--_dh, --_dm, --_ds). Without it, hands rest at 12:00. See basic/uiAnalogClock.js.

For features that require logic (timezones, dynamic numerals, localized numbering systems), see the web component demo.

Basic

Use the size attribute: sm (iOS home-icon size, 4rem), md (7.5rem), lg (15rem). Without size, the clock fills its container.

Stepping hands (steps)

By default all three hands sweep smoothly (linear). Add the steps attribute for classic tick-tick motion on seconds, minutes, and hours — like a quartz watch. Internally this sets --ui-analog-clock-hand-timing: steps(60); override that property directly for any other timing function.
